# 历史票据解析缓存与回收

每次读取仍完整枚举目录、读取全部文件字节、校验 UTF-8 并计算 SHA256；仅未变内容复用已成功解析和验证的内部对象。文件读取、编码、JSON、字段和目录错误保持原语义，不回退旧值。单票完整详情仍独立解析。

缓存最多 20000 条、64 MiB 原始内容权重、单项 1 MiB；这些不是 V8 堆或 RSS 上限。预算满时新项旁路，避免顺序扫描逐项驱逐整个热集合。替换、删除、切换共享目录、十分钟无调用和服务关闭均有回收路径；复用既有一分钟限频清扫，无新增生产计时器、强制 GC 或周期重启。

内部消费者不修改缓存票据；公开摘要复制 pauseReasons，其他投影重新构造，完整详情重新解析。保留既有返回值可变语义，没有逐轮深拷贝全部历史。
