## 2. 细则

- `world` 默认 `'launch'`，但 W1 阶段 launch / mech 都是占位模块 → 占位模块渲染测试台并在左上角标注「LAUNCH 场景待 W3」/「MECH 场景待 W2」，这样负责人打开看板就能看到横幅在工作。
- 事件订阅在 `WorkFloor.vue` 挂载时建立、卸载时退订；项目切换不重建订阅，只换过滤条件。
- `runtime.ts` 的循环是场景无关的：`start(tick)`, `stop()`, `setPaused(reason, on)`，30fps 用时间累积法而不是 setTimeout。
- 特效参数用普通对象，不要 class 继承树；每个特效文件顶部一段注释写清"画法对应样张哪一格、哪几层"。
- localStorage 只多一个键 `board-workfloor-ui`（折叠状态），逐字段校验。
- 所有新组件样式用 `base.css` 现有令牌（`--s*`、`--fs-*`、`--text-*`、`--card` 等），不写颜色字面量；场景内部调色板放 `scenes/bench/palette.ts`。
