# 质感标准 · 这个项目里所有画面稿与施工都要过的线

> 负责人原话（2026-09-08）："质感不对……像 AI 没出来前，Python 初学者通过画圆画矩形画出来的块状样式的动画。"
> 这份文件把"块状"到底是什么、怎么改，写成能逐条对照的标准。**每张派出去的画面工单都必须把本文列为必读**；验收时按 §3 逐条打勾，任何一条不过就打回。
> 可见的样张：`docs/mockups/质感样张-v1.html`（左边是块状画法，右边是合格画法，四组对照：火焰 / 烟 / 排气 / 光束）。

## 1. "块状"的七个病根（看到哪个就治哪个）

| # | 病根 | 块状的样子 | 合格的样子 |
|---|---|---|---|
| 1 | **形状用几何原型** | 圆就是烟、三角就是火、矩形就是雾、直线就是雨 | 有机轮廓（贝塞尔曲线、花菜边、火舌），同类物体每个都不一样（随机变异），边缘被噪声扰动 |
| 2 | **一物一色，明暗只是变深变浅** | 灰烟就是一个灰，火就是一个橙 | 冷暖分离：阴影偏冷（蓝紫）、亮部偏暖；多段渐变里有色相变化；环境色互相染（火光把烟底染橙、月光把顶面染蓝） |
| 3 | **边缘全硬、线稿一样粗** | 光、气、火、水都带黑边或硬边 | 光/气/火/水没有线稿、边缘软（模糊 + 半透明层叠）；实体物件线稿分级（外轮廓粗、内线细），受光边线稿变淡 |
| 4 | **没有空气** | 黑底上贴东西，光源没有辉光 | 大气透视（远处降对比、偏蓝、变淡）；每个光源周围有辉光和散射；探照灯、灯塔是体积光；夜景有薄雾 |
| 5 | **运动是刚体匀速** | 东西平移、旋转、突然出现突然消失 | 缓动（ease）、惯性、次级运动（旗飘、烟翻滚、火抖）；粒子有生命曲线（长大 → 衰减 → 淡出）；出现和消失都是渐变 |
| 6 | **所有东西在同一平面** | 前景背景一样清楚一样亮 | 分层：前景更暗更大略虚，中景主体最清楚，背景更淡更蓝；重叠遮挡说明前后 |
| 7 | **整齐划一** | 铆钉等距、灯一样亮、星星一样大 | 打破规律：间距略乱、亮度不一、大小三档、偶有污渍与磨损 |

## 2. 各类元素的做法（写工单时直接引用编号）

- **Q1 火焰**：三层贝塞尔火舌（白芯 / 橙幔 / 红外晕）+ 冲击菱；`feTurbulence + feDisplacementMap` 扰动边缘并动画化 `seed`；喷口大柔光；照亮地面与周围（橙色径向光 + 剪影叠色）；长度、宽度每帧抖动。
- **Q2 烟**：一团 = 6~9 个大小不一的软圆簇成花菜形，右下加体积阴影圆、左上加高光圆，整簇再过一次低频湍流扰动；受火光时底部染橙、受月光时顶部染蓝；寿命曲线：先贴地滚 → 长大上升 → 淡出。
- **Q3 冷气 / 排气 / 雾**：软椭圆叠三层，径向渐变白 → 透明；冷气**往下沉**并向外散；源头有雾丝；随时间长大、变淡、横向轻摆；密度随状态变。
- **Q4 光束**：至少两层楔形（内窄亮、外宽淡），沿长度衰减，模糊软边；灯室有光斑；照到的表面出现亮斑；不许穿过实体。
- **Q5 水面**：三层以上波浪曲线各自平移；月光带是碎的（断续亮片而非一条线）；倒影只在水面 clipPath 内、亮度 40%、经位移扰动；岸线有泡沫线。
- **Q6 天空**：渐变里有色相变化（深蓝 → 青灰 → 地平线暖灰）；星星三档大小、部分带辉光、少数慢闪；月亮带柔光晕和薄云遮挡。
- **Q7 雨 / 雪 / 碎片**：雨是带动感的细长渐变条（头亮尾透明），落地有溅水小弧；碎片是不规则小多边形，带重力、阻力、自转、弹跳。
- **Q8 烟花**：每颗粒子拖尾（彗尾渐变），爆开 → 下坠 → 淡出，有重力；核心爆闪一下；水面有倒影亮斑。
- **Q9 辉光与灯**：任何灯 = 灯体 + 亮芯 + 柔晕三层；同一排灯亮度不一样；灯下有光池。
- **Q10 实体材质**：金属（高光棱线锐 + 反射带）、混凝土（接缝 + 污渍 + 颗粒）、玻璃（斜向反光条 + 内发光）、橡胶/履带（哑光、深）。

## 3. 验收清单（画面工单的 M 项按这个打勾）

1. 放大 200%，画面里找不到"裸露的几何原型"当物体（圆当烟、三角当火、矩形当雾）。
2. 光、气、火、水没有黑边硬边。
3. 每个光源周围有辉光，且照亮了它该照亮的东西。
4. 阴影偏冷、亮部偏暖，火光和月光会互相染色。
5. 任何运动有缓动或惯性；粒子有生长-衰减曲线；没有硬出现硬消失。
6. 前景 / 中景 / 背景分得出来。
7. 同类重复元素有变化（大小、亮度、间距）。
8. 截图缩到 50% 仍分得清材质；放到 200% 每块面都有东西。
