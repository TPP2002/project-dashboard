## 0. 这幅画是干什么的

看板首页要放一幅"发射场"动画：一张任务卡 = 一枚火箭，卡片的每个看板事件对应画面里的一个真实动作，负责人扫一眼画面就知道项目在什么状态。它和 v9 的"机甲装配"是并列的两个世界，用户在设置里二选一。这一单只画发射场；两个世界的切换、白天版、多项目都是后面的单，**不要做**。

## 1. 从 v9 里继承什么（照抄，别自创一套）

1. **页面壳**：`.doc / .doc-head / .sec / .stage / .stat / .sim / .btn / .detail-list / .note` 这套 CSS 原样复制，文案区结构一致（标题、说明、01 整体、02 特写、03 下一步、页脚）。
2. **画法**：每块面 = 基色线性渐变（左上亮 → 右下暗）+ 上缘高光棱线（白 .28）+ 下缘硬阴影面（黑 .32）+ 深色面板线 + 铆钉；外轮廓 2.2px、内线 1.1px、`vector-effect:non-scaling-stroke`；全场统一左上光源（夜景里"光源"= 月光 + 探照灯，方向仍然左上）。v9 里的 `pg / hi / sh / ln / riv / circ` 这组小函数直接搬过来用。
3. **纹理**：v9 打磨后那套 `<pattern>`（拉丝、花纹钢板、洞洞板、斜纹警示条）+ 一层静态 `feTurbulence` 颗粒，同样的透明度纪律（≤ .08，颗粒 ≤ .05）。
4. **状态机**：`S` + `act()` + `auto()` + `frame()`（rAF 30fps）+ `render()`；七个按钮 `claim / pend / go / block / done / full / auto`；`after(ms, fn)` 定时器用"先收集到期项再执行"的写法（v9 已修过嵌套 after 丢失的坑）。
5. **纪律**：不用 emoji；不引外部字体/图片/库；颜色只用 v9 那套色板加发射场自己的几种（见 §3.8）；`prefers-reduced-motion` 下所有循环动画停、粒子不生成、镜头动作直接落位；不出现本机路径、主机名、其他项目名。

## 3. 火箭（做成可复用的绘制函数，三处用：VAB 内、履带车上、发射台上；特写再用一次放大）

1. 结构从下到上：三台发动机喷口（钟形 + 内壁暗 + 喷口环）→ 一级箭体（白/浅灰，竖向面板线、一道**项目色徽带**、若干铆钉排、"02"式编号贴花）→ 四片格栅翼（贴箭体、展开态）→ 级间段黑带 → 二级箭体 → 整流罩（尖头，一条接缝、一枚小舷窗）。总高约 190px（发射台上），宽约 26px。
2. 明暗：箭体是圆柱——左侧一条窄高光、右侧一条硬阴影面、中间基色；徽带同样跟着圆柱明暗。
3. **加注态**：进度 > 0 时箭体下半段出现结霜（白色不透明度随进度涨的竖向条 + 边缘碎块）、箭体侧面两三缕白雾（细长模糊多边形，缓慢向下飘、循环）；液位表同步。
4. **起飞态**（见 §4 done）：喷口下方点火：白色核心 + 橙黄外焰（`gFlame` 那种渐变改成暖色）+ 冲击菱（几段亮环），导流槽两侧涌出浓烟（粒子：圆 + 模糊，≤ 40 颗，向两侧再向上、朝海那边多飘），结霜碎片剥落下坠，摆臂摆开，火箭加速上升出画（约 3 秒），烟留 4 秒淡出。**没有回收段**：箭出画就结束。
5. 三处摆放：VAB 内总装台上（有台架、四根撑杆）；履带车上（车体 + 双履带 + 四根撑杆架着箭）；发射台墩上（四个固定夹合拢、摆臂搭上）。

## 4. 看板事件 → 画面动作（状态机；文字状态显示在指挥中心屋顶大屏）

| 事件 | 画面 | 大屏 |
|---|---|---|
| 未开工 | 火箭在 VAB 总装台上；避雷针红慢闪；一切安静 | READY |
| 认领 `claim` | 门内顶灯全亮 → 履带车驮火箭出门 → 沿履带路走到发射台（约 4 秒，履带纹滚动、车灯照路）→ 四个固定夹合拢、两条摆臂搭上、探照灯亮 | ROLLOUT |
| 进度（焊缝对应物）| 液位表按百分比涨；结霜、白雾随百分比增加；升降机上下跑；加注车在罐区来回；`stat` 里写 FUEL nn% | FUEL 62 |
| 待拍板 `pend` | 倒计时跑到 T-00:10 停住；一道闪电从云劈到避雷针（一次，光只照亮塔顶附近，**不许全屏白闪**）；探照灯转琥珀；指挥中心所有窗转琥珀；塔顶灯琥珀 | HOLD ⇄ GO?（每秒交替） |
| 拍板 `go` | 窗回青蓝；倒计时 10 → 0 每秒一跳；到 0 = 触发起飞（若卡还没完工则停在 T-00:01 等 done） | GO → T-00:09 … |
| 阻塞 `block` | 下雨（斜雨线层 + 天空压暗 + 场坪出现几片积水反光）；探照灯转红；摆臂重新搭上；倒计时清空；解除后雨停、回到 HOLD 或 FUEL | SCRUB（红） |
| 完工 `done` | §3.4 起飞序列；同一秒多张完工只放一枚、其余任务数直接加；箭出画后 VAB 里下一枚火箭挪到总装台 | LIFTOFF → NOMINAL → MISSIONS +1 |
| 项目 100% `full` | MISSION COMPLETE；海面上放三轮烟花（粒子，颜色用项目色 + 白）；旗换成项目色；发射台旁竖起纪念柱 | MISSION COMPLETE |
| 自动演 `auto` | 认领 → 加注涨到 100（约 12 秒）→ 每三枚有一枚中途 HOLD 3 秒再 GO → 倒计时 → 起飞 → 下一枚；跑完队列（3 枚）触发 100%，停 9 秒重置 | — |

`[data-stat]` 一行状态文字与 v9 同款：`火箭 2/5 · FUEL 62% · ROLLOUT`。

## 5. 特写（`[data-closeup]`，viewBox 400×690）

发射台局部放大：火箭 + 塔上半段 + 两条摆臂 + 避雷针。四个按钮：`总装（干净）/ 加注 60%（结霜白雾）/ HOLD（琥珀灯 + 闪电残光）/ 点火（火焰 + 烟 + 碎霜）`。用同一份绘制函数，不另画。

## 7. 性能与实现纪律

- 每帧只改小东西（火箭位置、粒子、液位、倒计时、履带车），大面积元素（天、海、楼）静态；海浪用三条 path 做 CSS `translateX` 循环，不用滤镜动画；倒影的位移滤镜静态一次。
- 粒子（烟、烟花、雨、碎霜）各自封顶：烟 ≤ 40、烟花每轮 ≤ 60、雨 ≤ 120 条线、碎霜 ≤ 20；用一个 `<g>` 每帧重写 innerHTML 即可。
- 闪电是一次性动作：一根折线 + 塔顶一圈亮光，200ms 内衰减；不许给整张天空加类不摘（v3 出过"背景黄色闪烁"的事故）。
- 所有循环动画在 `@media (prefers-reduced-motion: reduce)` 下停；JS 里 `matchMedia` 命中时履带车直接到位、火箭直接出画、粒子不生成。
