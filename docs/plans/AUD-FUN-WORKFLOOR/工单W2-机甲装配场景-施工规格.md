## 2. 数据接线（把 v9 的演示状态机换成真数据）

| SceneState | 画面 |
|---|---|
| `done` 数 / `total` | 部件按固定顺序（v9 的 `ORDER`）从脚到头点亮：已装块数 = `round(done.length / total × 29)`；`total` 变化时重新分配但不重放动画 |
| `active[0]` | 正在焊的那块 = 下一块未装的部件；焊缝长度 = 它的 `percent`；无人机停在它旁边打火花 |
| `active[1..]` | 零件架上标"待装"的件多几个带黄色吊牌（表示有人在排队焊） |
| `queued` | 零件架上的件数（最多 12，多的在标签条写 +N） |
| `pending[0]` | 当前焊的那块转 `pend` 态：琥珀闪、检验无人机飞来扫描；大屏 INSPECT? |
| `blocked` 非空 | 当前块 `block` 态、警灯、红光；大屏 JAMMED |
| `complete` | 全部点亮 + 通电悬浮（核心脉动、能量线、翼尖脚底喷焰）；大屏 POWER ON |
| 事件 `claim` | 无人机去零件架取件飞回（v9 的取件动画） |
| 事件 `progress` | 焊缝长度过渡到新 percent（缓动 600ms） |
| 事件 `hold` / `go` | 挂检验 / 盖章继续（v9 pend/go） |
| 事件 `block` | 卡件序列（v9 block） |
| 事件 `park` | 无人机回停机位，当前块保持半透明，大屏 PAUSED |
| 事件 `done` | 白闪扣上，剪影多亮一块，大屏 PARTS n/29 跳 |
| 首帧 | 按状态直接摆好，不播动画（总契约 §5.2） |

大屏事件三行来自真实事件（CLAIM / WELD 62% / DONE …，用卡的 `id` 缩写到 12 字符）。`aria-label` 例：「机甲装配：已装 17/29，正在焊左肩甲 40%，2 件待拍板」。

## 3. 质感（对照 v9 落地版 + 质感标准）

- 焊接火花、弧光、扫描线、焊缝辉光用 `fx/sparks`、`fx/drone`；喷焰用 `fx/flame` 的小号参数；全息投影锥有扫描线纹理；探照灯光锥两层。
- 白天版留接口：`setDayNight('day')` 时至少把大门外天光、探照灯关、墙面提亮（完整白天调色板 W4）。
