## 1. 交付

`scenes/launch/` 下：
- `layout.ts`：构图常数（PAD_X / MOUNT_TOP / BODY_R / TOWER_X / ARM 高度、履带路 path、海面多边形、岸线）。
- `palette.ts`：夜景调色板 + 白天占位（W4 填）。
- `rocket.ts`：火箭绘制函数（三处摆放 + 结霜/排气挂点）。
- `site.ts`：静态场景（天空星月云、海与倒影、VAB、储罐区、指挥中心、塔与台、灯塔、前景道具）。
- `screen.ts`：指挥中心大屏文字状态与 MISSIONS 计数。
- `index.ts`：`createLaunchScene(host, ctx): SceneHandle`。
- 特效一律用 `fx/` 库（W1 已搬进去的那九个），**不要在场景里再抄一份**；库里不够用的参数，改库（允许改 `fx/**`，改动写进 summary）。

## 2. 数据接线

| SceneState | 画面 |
|---|---|
| `queued` | VAB 门内排队的火箭，最多露 3 枚，其余计数写在门框标牌 `+N` |
| `active[0]` | 台上那枚：液位表 = `percent`，结霜 / 排气随之；大屏 FUEL nn；`percent ≥ 90`（收官）进入倒计时段 T-00:10 待命 |
| `active[1..]` | 履带路上等候的第二台履带车（只露一台，其余在 VAB） |
| `pending[0]` | 台上那枚 HOLD：倒计时停在 T-00:10，闪电、琥珀灯，大屏 HOLD ⇄ GO? |
| `blocked` 非空 | SCRUB：下雨、红灯、摆臂搭回 |
| `done` 数 | MISSIONS 计数 = `done.length`；纪念柱 = `complete` 为真时出现 |
| `complete` | MISSION COMPLETE、海上三轮烟花、旗换项目色 |
| 事件 `claim` | 履带车驮箭出门、拐弯、上台、落座、夹合、臂贴（v10 序列，约 5 秒） |
| 事件 `progress` | 液位缓动到新值 |
| 事件 `hold` / `go` | HOLD 序列 / GO 倒计时 10→0（到 0 若未完工停在 T-00:01） |
| 事件 `block` | SCRUB 序列；解除后回 HOLD 或 FUEL |
| 事件 `park` | 倒计时清空、探照灯减半、火箭留台、大屏 STANDBY |
| 事件 `done` | 点火起飞出画（无回收），MISSIONS +1，下一枚从 VAB 出来；同一秒多张只放一枚 |
| 首帧 | 按状态直接摆好（台上有没有火箭、液位多少、VAB 几枚），不播动画 |

`aria-label` 例：「发射场：3 枚待发射，1 枚加注 62%，累计发射 57」。

## 3. 质感要求（这一单的重点，负责人是细节狂）

- 光束：按样张第 04 格做足（内窄外宽、朝向亮度、扫海亮斑）；v10 里偏细，这里必须到位。
- 烟：程序化云（样张 02，噪声蒙版 + 位移 + 明暗层错位 + 火光染底）；火焰：三层火舌 + 冲击菱 + 照亮台面。
- 排气：样张 03 的连续下沉一股。
- 海：三层波浪各自平移、月光碎带、倒影只在海面 clipPath 内并经位移扰动。
- 白天留接口（天空/海/灯的调色板切换），完整白天版 W4。
