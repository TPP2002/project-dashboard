## 1. 它是什么

看板页（`web/src/views/Kanban.vue`，路由 `/kanban`）顶部多一条**施工现场横幅**：一幅 SVG 动画场景，把当前项目的任务状态画成"一个世界里正在发生的事"。两个世界二选一：**机甲装配**（一张卡 = 一块装甲，焊上去）和**发射场**（一张卡 = 一枚火箭，点火起飞）。看板事件（认领 / 进度 / 待拍板 / 拍板 / 阻塞 / 完工 / 项目 100%）各对应画面里一个动作。

## 2. 放在哪、怎么切

- 横幅位于页头（标题 + 进度条）之下、泳道之上，**全宽**，视口比例 1400:520 按容器宽缩放，高度上限 `min(44vh, 520px)`；「紧凑」档用 1400:360 的中段裁切（场景自己决定裁哪段，主体必须在裁切内）。
- 右上角一枚折叠按钮（用现有精灵图标，`Icon` 组件），折叠后只剩 36px 高的一行状态文字（如「发射场 · 3 枚待发射 · 1 枚加注 62%」）；折叠状态记本机（localStorage，逐字段校验）。
- 没选项目 / 看板没加载 / 世界设为「关」时，横幅整体不渲染（不占高度）。
- 切换项目或世界：旧画面 300ms 淡出 → 新画面淡入；切换时不重放历史事件。

## 5. 数据接线（bridge.ts，纯函数，必须有单测）

### 5.1 场景状态 `SceneState`（每次看板刷新后重算，场景只吃它）

```ts
interface SceneTask { id: string; title: string; percent: number /*0~100*/; status: Status; order: number }
interface SceneState {
  projectId: string
  projectName: string
  queued: SceneTask[]     // 待开工 / 可复工（按 wave, id 排）
  active: SceneTask[]     // 施工中（按认领时间 dates.claimed 或 id 排，最早的排前面）
  pending: SceneTask[]    // 待拍板
  blocked: SceneTask[]    // 暂缓
  done: SceneTask[]       // 已完工（按完工日排）
  total: number           // 不含已作废
  percent: number         // derive.progress 的口径
  complete: boolean       // total > 0 && done.length === total
}
```
- 已作废（`VOID_STATUSES`）不进任何列表也不计 total。口径与 `web/src/utils/derive.ts` 的 `progress()` 一致（复用它，别再算一遍）。
- `percent` 缺省 0，夹到 0~100 整数。

### 5.2 事件 `SceneEvent`（来自 `web/src/utils/boardEvents.ts` 的 `onBoardEvent`）

| 看板事件 kind | SceneEvent | 机甲 | 发射场 |
|---|---|---|---|
| `claim` | `claim` | 无人机取件、开焊 | 履带车转运上台 |
| `progress` | `progress`（带 percent） | 焊缝长度 | 液位表 |
| `pending` | `hold` | 挂检验单、检验机来 | T-10 HOLD、闪电 |
| `decide` | `go` | 盖章、继续焊 | GO 倒计时 |
| `block` | `block` | 卡件红闪、警灯 | SCRUB 下雨 |
| `park` | `park` | 无人机停机、部件半透明 | 倒计时清空、火箭留台、灯变暗 |
| `done` | `done` | 扣上白闪 | 点火起飞 |
| `note` | 忽略 | | |
| （派生）`complete` | 状态里 `complete` 从 false 变 true | 通电悬浮 | MISSION COMPLETE |

- 只处理 `event.projectId === 当前项目` 的事件。
- **页面刚打开不重放历史**：首帧直接按 `SceneState` 摆好（已装的装上、台上的立好），之后才播事件。
- 同一秒内多张完工只播一次动画，其余直接计数（v10 已有此逻辑，照搬）。
- 事件与状态不一致时以状态为准（例如收到 `done` 但刷新后那张卡不在 done 里，动画照播、下一帧按状态修正）。

## 6. 特效库 `fx/`（从三份稿子里搬，改成可复用的 TS）

每个特效 = `create(hostGroup, params) → { update(dt, params), destroy() }`，输出 SVG 元素而非字符串拼接（首帧可以 innerHTML，之后只改属性）。**画法必须与样张一致**（`质感样张-v1.html` 右列）：
- `flame`：三层贝塞尔火舌 + 冲击菱 + feTurbulence 扰动 + 喷口柔光 + 照亮周围（回调给场景：当前火光强度）。
- `smoke`：程序化云（噪声蒙版 × 软形状 + 位移）+ 明暗层错位 + 火光/月光染色；粒子封顶由 `detail` 档决定（极致 70 / 标准 35）。
- `vent`：连续下沉的一股冷气（样张 03）。
- `beam`：两层楔形软边光束 + 灯室三层光斑 + 照到面上的亮斑 + 朝向亮度。
- `lightning`：三层描边折线 + 分叉 + 爆闪 + 被照亮的剪影回调（场景传入要照亮的 clipPath）。
- `frost`：不规则碎片、重力阻力自转、落地弹一次。
- `sparks`：焊接火花（v9）。
- `drone`：焊接 / 检验无人机（v9），带悬停摆动与飞行插值。
- `path`：沿 `<path>` 走的载具（履带车、加注车），车头随切线，端点掉头（v10）。
所有滤镜 `<defs>` 由 `fx/defs.ts` 一次性注入宿主 `<svg>`，id 加前缀 `wf-` 防撞。

## 7. 性能与降级（硬指标，W1 就要做进 runtime）

- 一个横幅只有一个 `<svg>`、一个 rAF 循环，30fps 上限；`document.hidden` 或横幅离开视口 → 暂停；恢复时不补帧。
- 每帧只改属性；只允许两个粒子组用 innerHTML 重写；滤镜只挂在小组上（火、闪电、单团烟），不挂全屏。
- `prefers-reduced-motion`：不跑循环，事件直接跳到终态（火箭直接消失并计数、部件直接扣上），仍然显示静态画面。
- 极致档在 1400px 宽的横幅上，Chrome 性能面板 scripting + rendering 每帧 ≤ 6ms（在 W2/W3 验收时测）。
- 横幅容器 `contain: content`；SVG 上 `shape-rendering: geometricPrecision` 只用于线稿组。

## 8. 昼夜与主题

- `dayNight='theme'`：`web/src/utils/theme.ts` 解析后的实际主题，浅色 = 白天；`'clock'`：本机 06:00~18:00 白天；`'night'`：永远夜景。
- 场景通过 `SceneHandle.setDayNight('day'|'night')` 切换调色板与灯光（W4 才做白天调色板，W2/W3 先把接口留好并在白天时至少把天空/背景换成白天色）。
- 项目色：横幅里"项目色"的元素（火箭徽带、集装箱、旗、机甲核心）读现有项目色机制（`AppearanceProjects` / registry 的 color），没有就用 `--spec-active` 第一档。

## 9. 无障碍与文案

- 横幅 `role="img"`，`aria-label` 每次状态变化更新为一句人话（世界名 + 数量 + 当前动作）；折叠按钮有 `aria-expanded`。
- 画面里的文字只用 `ui-monospace` 英文短语（READY / FUEL 62 / WELDING …）和数字；界面文案（设置项、折叠行）中文；**不用 emoji**；图标只用 `web/src/icons` 现有精灵。
