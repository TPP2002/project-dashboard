## 0. 先读懂这份稿的结构（10 分钟）

打开文件，从上到下：

1. `<style>`：页面壳 + 机甲部件状态样式。关键：`.mech .part` 上的 CSS 变量 `--fo/--so/--ol`（填充透明度 / 描边透明度 / 描边色）由状态类 `off/build/pend/block/done` 切换；`.pl` 是有描边的板，`.pl.main` 是外轮廓（2.2px），`.hi/.sh` 是高光/阴影面，`.ln` 面板线，`.riv` 铆钉，`.glow` 发光件，`.thr` 喷焰，`.eline` 能量线，`.cable` 线缆。
2. `<script>` 第一段：几何。`PARTS` 里每块部件 = `{ name, main（外轮廓点阵，焊缝/剪影/货架都用它）, build()（返回 SVG 字符串）, rings, dx }`。`sided()` 写左半边、镜像出右半边；`dx` 是整块横移（四段手臂 ±30）。`DEFS` 是渐变与滤镜。`mechSvg()` 把 29 块拼成 `<g class="mech">`。
3. 第二段：机库场景 `[data-scene]`（viewBox 1400×520）。背景墙、管线、探照灯、龙门塔、地面、零件架 `[data-rack]`、大屏 `[data-board]`、平台、全息投影锥、机甲（`translate(564,34) scale(.68)`）、焊缝 `[data-seam]`、扫描线 `[data-scan]`、火花、两架无人机。
4. 状态机 `S` + `act()` + `auto()` + `frame()`（rAF 30fps）+ `render()`。`render()` 每帧重写部件类名、大屏文字、平台环、货架里的待装件、焊缝长度。
5. 第三段：特写 `[data-closeup]`（同一份几何放大）+ 四个模式按钮。

页面里的说明文案（`.detail-list`）描述的就是现状，改完什么就同步改文案，别让文案和画面对不上。

## 1. 必修 bug：双手不停左右横移

**现象**：页面打开后，两只手臂（上臂、肘、前臂、手）每 3.4 秒左右横跳一次，位移约 20px（缩放后）。

**病根**：`.mech.idle .torso{animation:breathe 3.4s …}`，`@keyframes breathe{50%{transform:translateY(-2px)}}`。四段手臂的 `<g class="part">` 上带着属性 `transform="translate(±30,0)"`（`mechSvg()` 里 `translate(${p.dx},0)`）；CSS 动画的 `transform` 会**整个替换**属性 transform，于是动画一半的时候手臂丢掉了 ±30 的横移，回到中线，再跳回去。

**修法（二选一，都要保证扫描线位置不错）**：
- A（推荐）：`mechSvg()` 里把横移放到**外层包一层** `<g transform="translate(dx,0)"><g class="part …">…</g></g>`，`.part` 自己不再带属性 transform。
- B：把 dx 写进 CSS 变量（`style="--dx:30px"`），三组 keyframes（breathe / hover）全部改成 `transform:translate(var(--dx,0),-2px)` 这种带 dx 的写法。

同时：`render()` 里扫描线用 `partEls[S.target].getBBox()` 取部件包围盒——方案 A 下 `getBBox()` 返回的是未横移的局部坐标，手臂四段会偏 30。改成**用 `byName[name].main`（已含 dx）算包围盒**（min/max x,y），不再依赖 getBBox。

验：打开页面盯 10 秒，双手不再横跳；`act('claim')` 走到前臂时扫描线要压在前臂上，不是压在身体上。

## 2. 零件架（右侧 `[data-rack]`）——负责人原话"没有纹理"

现状是一块平的深色矩形 + 三根横条，太素。要改成一座**真的工业零件架**，全部矢量，同一套赛璐璐画法（基色渐变 + 上缘高光 + 下缘硬阴影 + 深色描边）：

1. **背板**：洞洞板（pegboard）——用 `<pattern>` 铺规则圆孔（孔 r≈1.6，间距 10，孔色比背板深两档），背板本身带轻微竖向拉丝（第二个 `<pattern>` 细竖线，不透明度 ≤ .08）。
2. **立柱**：左右两根带螺栓孔的槽钢（每 24px 一个孔，孔里有更深的一点），顶端有加强角撑。
3. **层板**：三层，每层有厚度（上表面亮、前缘一条更亮的高光、下面一条硬阴影投在背板上），前缘贴**标签条**（白底浅灰、上面一小段条码 = 若干粗细不一的竖线 + 货位编号 `A1 / A2 / B1 …`，字体 `ui-monospace`，字号 ≤ 9）。
4. **待装件**：`render()` 里目前把 `off` 状态的部件外轮廓缩到 60×60 排 4×3；改成**摆在层板上**（底边落在层板上表面，不是悬空居中），每件下面一小片椭圆接触阴影，每件用 `gBlueD` 渐变 + 深色描边 + 一道高光棱线，件旁贴一枚小吊牌（矩形 + 细绳线）。件数超过格位时只画前 12 件，标签条上写 `+N`。
5. **架顶工具板**：一小段挂工具的板：两把扳手、一卷线缆、一支焊枪，全部用多边形/圆弧画（不许 emoji、不许图片），尺寸小、颜色低饱和，别抢戏。
6. **底部**：底座横梁 + 黄黑警示条（斜纹 pattern），一枚绿色小 LED（架子在线）。
7. 架子整体在探照灯下：右上探照灯的光锥已经打到架子（`gCone`），架子顶面要比侧面亮一档，体现受光。

## 3. 左侧大屏 `[data-board]`——负责人原话"效果差了一点"

现状：黑矩形 + 剪影 + 大字。要做成一台**真的工业控制台显示器**：

1. **外壳**：深灰金属边框（渐变 + 描边），四角螺钉（小圆 + 十字线），底部一条铭牌（`ASSEMBLY CONSOLE · BAY 02`，字号 9），右下两枚实体按钮（一红一青，带下阴影）。
2. **玻璃**：屏幕区叠三层——①底色近黑带轻微青色内发光（`feGaussianBlur` 或径向渐变）；②**扫描线** pattern（1px 亮线 / 3px 暗，透明度 ≤ .07）；③左上到右下一条斜向**玻璃反光**条（白，透明度 .04~.06）。
3. **内容布局**（左 1/3 剪影区，右 2/3 数据区）：
   - 标题栏：`ASSEMBLY // BAY 02`，右侧一个 `REC` 圆点闪 + 时钟 `HH:MM:SS`（JS 每秒更新）。
   - 剪影区：网格底（细线 pattern），剪影用青色 + 发光滤镜；**当前在焊的部件**在剪影上用琥珀色高亮（`done` 青、`build/pend/block` 按状态色、`off` 深蓝）。
   - 大百分比（保留），下面一条 **29 格分段进度条**（每格一块部件，已装亮青、焊接中黄闪、阻塞红、未装深色）。
   - 状态行：彩色 LED 圆点 + 文字（STANDBY 青 / WELDING 青 / INSPECT? 琥珀 / JAMMED 红 / POWER ON 绿），沿用现有 `data-status`。
   - **事件滚动条**（3 行）：最近三条事件，如 `CLAIM  L-SHOULDER` / `WELD   L-SHOULDER  40%` / `DONE   L-FOREARM`，新事件从下面推入、旧的上移淡出（CSS transition 即可）。事件在 `act()` 各分支里 push。
   - 底部一条**示波器线**：一条折线 `<polyline>` 用 `stroke-dasharray` + `stroke-dashoffset` 动画做成持续流动的波形（通电时振幅变大、颜色变绿）。
4. 所有文字 `ui-monospace, Consolas, monospace`，字号分级（标题 12 / 数据 11 / 注脚 9），青色 `#34d7ff` 为主，琥珀 `#ffb020`、红 `#ff4d5a`、绿 `#8affc1` 只用于状态。

## 4. 全场质感（"没有纹理"的根子：大面积纯色平涂）

在**不改机甲几何**的前提下，给场景加"看得见但不抢戏"的纹理，全部用 SVG `<pattern>` / `<filter>`，静态、一次性，别加每帧重算的东西：

1. **墙面板**：每块面板加细密的斜向拉丝 pattern（透明度 .05）+ 面板边缘一圈 1px 亮边/暗边（体现板厚），随机几块面板有污渍（低透明度不规则多边形，深色）。
2. **地面**：花纹钢板（diamond plate）pattern 或格栅 pattern（透明度 .08），平台周围一圈磨损（浅色划痕线若干）。
3. **平台**：同心圆刻线 + 外圈黄黑警示斜纹（pattern）。
4. **颗粒**：整场最上层压一张 `feTurbulence` 噪声（`baseFrequency≈.8`，`numOctaves 2`，经 `feColorMatrix` 压成灰度、透明度 ≤ .05），让平涂有"纸感"。用 `mix-blend-mode: overlay` 或直接低透明度叠加，二选一，看哪种在深色底上不发灰。
5. **管线与栏杆**：管线加一条高光线（体现圆柱），法兰处两道箍；栏杆立柱加底座。
6. **探照灯**：灯罩里加灯泡亮点 + 灯罩内壁渐变；光锥加轻微的体积雾（两层锥，外层更淡）。

判据：把整张场景缩到 50% 看仍然分得清"这是金属、这是地面、这是屏幕"，放到 200% 看每块面都有东西可看。

## 5. 动效降级（补上）

稿子目前没有 `prefers-reduced-motion` 处理。加：`@media (prefers-reduced-motion: reduce)` 下停掉 breathe / headsway / hover / blink / rotor / rgbflow / 示波器 / 事件条过渡，JS 里 `matchMedia('(prefers-reduced-motion: reduce)').matches` 为真时无人机直接落位不插值、火花不生成。
