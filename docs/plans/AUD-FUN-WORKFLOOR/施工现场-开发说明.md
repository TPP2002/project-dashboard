## 模块与接线

`AppearanceWorkfloor` 使用外观中心同一套控件和 `setAppearance`。六项设置（world / dayNight / detail / height / position / soundLink）保存在原有外观存档；归一化逐字段接收合法值，坏字段回默认。`resetAppearance` 也会恢复整组设置。

`WorkFloor` 默认在泳道下方贴底，可在外观中心改到页头之下，接收 `board`、`projectId`，并只读项目颜色设置和项目清单。未选择项目、无看板或世界为 off 时不占空间。折叠后为 36px 状态行；折叠存档只有一个布尔字段。主题跟随系统深浅变化；时钟模式启用一分钟定时器，并在模式切入及页面恢复时立即读取本机小时。设置与折叠存档仍走原有逐字段校验。

`bridge.ts` 不依赖 Vue、Pinia 或 DOM。统计复用 `derive.progress`；十一状态按总契约映射。`SceneTask.order` 是分组内从零开始的排序位置，任务进度先夹到整数边界，收官再取至少 90。输入不会被改写，空看板和全作废看板都不视为完成。

`mapBoardEvent(event, projectId?, state?)` 支持单事件映射和显式项目过滤。当前事件总线没有 percent，因此容器从 store 的最新快照补齐。完工事件先交给旧工位保存动画，再送新快照；其它事件先送快照再送事件，以取得认领后的分组和最新进度。这里直接读取 store 是为了避开父组件 props 尚未刷新的一小段同步时间。订阅只在挂载时建立、卸载时退订，项目切换不重新订阅，也不读取历史活动列表。

## 世界接口

公开入口 `createWorkfloor(svg, options)` 返回 `update(options)`、`handleEvent(event)`、`destroy()`。宿主必须是已挂载的唯一 SVG。`options` 包含 world、state、dayNight、detail、height、collapsed、sound 和 onError；可注入 `now` 供展示事件时间与完工合并使用。不要从场景直接访问 store。

场景模块导出 `createScene: SceneFactory`，返回 `SceneHandle`：

| 方法 | 责任 |
| --- | --- |
| `setState(state)` | 首帧直接摆好；后续保存最新快照，保留进行中的完工动画，结束后按快照整理；不得修改输入 |
| `handleEvent(event, animate)` | animate 为 false 时直接落位；done 仍须计数，不丢掉事件 |
| `tick(dt, elapsed)` | 单位均为毫秒；elapsed 只累计实际运行时间 |
| `setDayNight(dayNight)` | 接收解析后的 day / night |
| `setDetail(detail)` | 标准档粒子减半，去掉位移滤镜 |
| `setHeight(height)` | 设置 viewBox，中段裁切须保留主体 |
| `setReducedMotion(reduced)` | 减少动效时保持静态，事件直接落位 |
| `setSound(sound)` | 接收可选的 `(cue: SoundCue) => void` 回调；传 undefined 即取消声音出口 |
| `destroy()` | 移除自己创建的节点、局部 clipPath 和特效实例 |

注册表保留 launch / mech 的动态 import，主入口不直接导入两个世界。`scenes/mech/index.ts` 与 `scenes/launch/index.ts` 已提供真实场景。`scenes/bench/index.ts` 保留独立 `createScene`，包含特效展位和真实场景复现按钮，不新增路由或设置项。

切项目或世界先淡出 300ms，再创建新场景并淡入 300ms。异步切换使用代次校验；过期的加载结果不会挂回宿主。切换期间收到的事件不排队重放，新场景按最新快照初始化。首次载入已经完成的项目不发 complete；之后 false → true 才派生 complete。按事件时间的整秒合并 done 动画，每个 done 仍送到场景；重复秒用 animate=false 标识，状态计数始终来自快照。

## 特效调用与调试

每个特效导出 `create(group, params)`，返回 `update(dt, params)` 和 `destroy()`。group 必须已挂在 SVG 中；位置和比例由外层 group 变换提供。通用参数是 detail、reducedMotion、enabled。所有实例只修改自己的子节点，不启动循环，不用位图或新增图标。

| 模块 | 参数和画法 |
| --- | --- |
| flame | intensity、length、onLight；三层贝塞尔火舌、冲击菱、湍流、喷口及地面柔光 |
| smoke | fireLight、moonLight、daylight；70 / 35 团固定池，实体底、噪声蒙版、错位明暗、暖底冷顶；白天实体底更白、阴影更淡 |
| vent | density；28 / 14 组下沉气流，源头雾丝和地面冷雾 |
| beam | length、angle、sweep、innerHalfAngle、outerHalfAngle、surfaceX、surfaceClip；双层软楔形、三层灯室和裁切受光面 |
| lightning | period、length、silhouetteClip、onLight；三层通道与分叉、局部闪光、余辉及剪影受光 |
| frost | floor；32 / 16 片，重力阻力、自转、单次弹跳、落地渐隐 |
| sparks | intensity、floor、onLight；48 / 24 条暖色拖尾，重力与阻力、落地一次反弹、寿命渐隐；弧光回调供相邻装甲受光 |
| drone | target、mode（weld / inspect）、working；缓动飞行、悬停、螺旋桨、焊枪和检验束 |
| path | path（实际 SVGPathElement）、kind（crawler / fuel）、duration；沿切线行驶，端点缓停掉头 |

测试台中间九个展位持续演示；闪电周期 6000ms，右上只保留最近五条实时事件。状态摘要包含各分组计数和总进度，另列前三个施工任务的进度。标准与紧凑 viewBox 分别为 `0 0 1400 520` 和 `0 80 1400 360`，九个展位及摘要均在裁切范围内。

`fx/defs.ts` 每个宿主只注入一次共享 defs。滤镜、渐变和裁切 ID 使用独立 `wf-` 前缀；单个特效不移除共享 defs，由总入口最终清理。世界可复用 `ensureDefs`，但不能自行驱动它的时间。标准档选择没有 feDisplacementMap 的滤镜版本；滤镜仅挂局部特效，未挂整幅画面。通用颜色来自 `base.css` 色站，两个世界的审定原色保留在各自 `palette.ts`；W4 白天配色组合既有颜色引用，没有新增颜色字面量。项目色优先本机覆盖，再取合法登记颜色，最后回落当前光谱首色。

## 循环、降级与验证边界

运行器只有一个 requestAnimationFrame 循环，通过时间累积限到每秒 30 帧。后台、离屏、折叠、切换以及减少动效使用独立暂停原因；恢复时清空上一帧基准和余数，卡顿也不补帧。减少动效不申请动画帧，只在状态或事件变化时直接画静态终态；切换淡入淡出也立即结束。粒子池在创建时分配，每帧不拼 innerHTML、不重建节点，未变化的属性不重复写入。

## 昼夜与白天配色（W4）

`daynight.ts` 的 `resolveDayNight(setting, theme, hour)` 是纯函数，没有 Vue、DOM、存储或时钟依赖。`theme` 使用 `utils/theme.ts` 的选择及系统深色媒体查询解析出的实际主题；`clock` 在本机 06:00（含）到 18:00（不含）为白天；`night` 不受主题和小时影响。`WorkFloor` 经 `update(options)` 将结果送到场景的 `setDayNight`。单测覆盖两种实际主题、三种设置及端点两侧。

两世界使用 `paletteTransition.ts` 消费同一个宿主 tick，在 600ms 内平滑插值环境色和灯光透明度。途中反向从当前比例继续；初次挂载直接取目标色，减少动效时立即落位；隐藏、离屏、折叠时与场景一同暂停，不新增动画定时器。

机甲白天打开机库门的天光层，暖白到青灰的门外渐变在地面形成亮区；墙和地面提亮，全息投影变淡。泛光灯和光锥淡到零，控制台颜色不变。焊接白光裁切到当前及相邻的可见装甲，强度为弧光的 .25；火花使用局部地面高度，只反弹一次。

发射场白天使用晴空、暖白地平线和更蓝的海，显出右上太阳与柔光，隐藏星月，增强白云与海上碎光。太阳与灯光倒影共用水面裁切和原有位移滤镜；探照灯、路灯和灯塔的光束淡到零，灯体保留。指挥中心窗户变成不发光玻璃，厂房门内顶灯仍亮但减弱对比。点火火光减弱，烟底提亮为白色；程序化烟仍保留噪声蒙版、位移和错层明暗，不换成软圆。

灯塔光程 420、内外半角 5° / 12°，源头 .55 衰减到零；探照灯采用同样开角并在碰到实体前截断。扫海光斑半径为 150 × 19，限制在水面内。起飞动画 3400ms，烟在起飞结束后最多再保留 4000ms。

紧凑档沿用机甲整座平台的等比缩放与 `0 80 1400 360` 裁切；发射场为 `0 94 1400 360`，火箭、塔及台基在裁切中，构图和几何未重画。实际画面及运行性能仍由 M1 核对。

## 声音出口（W4）

`SceneOptions.sound` 与 `SceneHandle.setSound` 接收可选回调，接口类型来自 `workfloor/types.ts`。场景不读声音设置，不负责音量或静音时段，也不创建音频上下文。只在实时动作被接受时发 cue；初次快照不补播，同秒合并的后续完工不重复发 cue。

| 世界 | 动作 | cue |
| --- | --- | --- |
| 机甲 | 取件结束开始焊接、拍板恢复焊接 | `weld` |
| 机甲 | 盖章、卡件、扣上、通电、挂检验单 | `stamp`、`alarm`、`done`、`complete`、`hold` |
| 发射场 | 点火、离台（点火后 400ms） | `ignition`、`liftoff` |
| 发射场 | HOLD、SCRUB、MISSION COMPLETE、GO | `hold`、`alarm`、`complete`、`stamp` |

容器在 `soundLink && appearance.sound` 时提供回调，并用 `import.meta.glob<SoundPlayer>('../utils/sound.ts')` 查找可选模块。模块缺席时映射为空，没有无法解析的静态 import；模块存在时动态加载并调用 `playSound(cue)`。加载、播放失败静默；加载后重新检查开关、项目、世界及组件是否卸载。音量和静音时段完全由未来声音模块读取。新增该模块后须重新构建，已经发布的空映射不会自行发现部署后另加的源码。

## 动画队列与刷新（W4）

机甲 `machine.ts` 的 `finishing` 按任务保留白闪路径，700ms 到期才回收。`setAssembly` 只改基础装甲，不会删除队列节点，通电、其它事件及同秒后续完工也不会覆盖白闪。警灯与红色洗光只由 `block` 事件触发 2600ms，平时透明度为零；样式不再用固定透明度覆盖逐帧属性。暂缓部件常态保留红描边，不闪烁。大屏常态优先通电、待拍板、施工、阻塞、待机；当前页 `park` 的停机表示继续保留。

发射场 `sequence.ts` 的 `flights` 是单发射台的进行中队列。旧快照、完工快照和同秒其它完工都不能删掉在飞的火箭，等待车辆安全撤离的点火请求也不会被未到达的完工状态取消。起飞结束后按最新快照接班或落位；最后一张完工时，完成提示与庆祝 cue 等起飞结束再发。转运对象在搬运与落座夹合期间一直保留 `ROLLOUT`，其它卡的暂缓状态刷新不取消它；5900ms 后按最新状态进入加注等常态。

发射场常态的台上任务固定取 `active[0] ?? pending[0] ?? blocked[0]`，不因其它卡收到 `park` 或暂缓而换台。大屏与天气按所选任务的分组决定：

| 台上任务所属分组 | 常态大屏与天气 |
| --- | --- |
| active | `FUEL` / 倒计时；所选卡已拍板或收到 `go` 时为 `GO`，其它卡不重置倒计时 |
| pending | `HOLD`，琥珀提示 |
| blocked | `SCRUB`，雨天与红色提示 |
| 台上无任务且 complete | `MISSION COMPLETE` |
| 台上无任务且未 complete | `READY` |

实时 `block` 事件临时覆盖大屏与天气为 `SCRUB`，下雨、转红 4000ms；`hold` 临时覆盖为 `HOLD`，琥珀提示并在 400ms 后触发闪电。提示从首次接受事件时计时，重复事件与快照刷新不延长；4000ms 到期后重新按**最新**台上分组计算，不保留旧相位。该卡仍为所选 pending / blocked 时分别继续 `HOLD` / `SCRUB`，已离开 pending 或只是其它卡时回到台上任务的常态。没有事件时，其它暂缓卡不改变雨天、窗户颜色或大屏；本实现不额外显示其它暂缓卡的计数。

`LaunchFrame.phase` 统一供大屏、雨、闪电、云层、窗户与信号颜色使用；`motionPhase` 保存转运、夹合、加注、等待点火和起飞进程，有限时长的提示不取消这些动作，也不拦住下一枚 active 火箭接班。提示到期后，尚未结束的动作继续显示 `ROLLOUT` / `LIFTOFF` 等动作相位，动作结束再显示上述常态；无台上任务时不额外停留在 `NOMINAL`。首次快照不补播事件，禁用动画或减少动效时不启动临时天气；切项目、开启减少动效会清除临时天气。

**不能只靠单测验收的部分**：纯逻辑测试能证明队列时长、屏幕状态优先级和同秒合并，不能证明浏览器中的实际 SVG 节点未闪断、属性更新与绘制顺序正确，或滤镜/裁切后的完整画面。因此 M1 必须在探针实例实际观看两个世界的连发动作，静态源码或这里的逻辑验算不代替它。

测试台选「机甲」或「发射场」，再点「连发 done + update」。按钮重新挂载该真实场景，依次同步发送：首卡 done → 旧快照 → 首卡已完工快照 → 同秒次卡 done（不重复动画）→ 全完工快照 → complete。应看到机甲白闪完整 700ms、火箭完整起飞后才显示 MISSION COMPLETE；途中计数已更新为 2。返回特效恢复原九个展位。该入口只使用合成任务，不连接 store、不改真实卡，也不额外启动帧循环。

已有探针可直接挂 `scenes/bench/index.ts` 的 `createScene`。若探针尚未挂载，在开发服务器页面的开发者控制台运行以下独立挂载示例；核完执行 `stopWorkfloorBench()` 清理：

```js
const [{ createScene }, { createRuntime }, { ensureDefs, removeDefs }] = await Promise.all([
  import('/src/workfloor/scenes/bench/index.ts'), import('/src/workfloor/runtime.ts'), import('/src/workfloor/fx/defs.ts'),
])
const svg = document.createElementNS('http://www.w3.org/2000/svg', 'svg')
svg.style.cssText = 'display:block;width:100%;aspect-ratio:1400/520;background:var(--wf-stage)'
document.body.prepend(svg)
const state = { projectId:'bench', projectName:'测试台', queued:[], active:[], pending:[], blocked:[], done:[], total:0, percent:0, complete:false }
let scene
const runtime = createRuntime(svg, reduced => scene?.setReducedMotion(reduced))
scene = createScene(svg, { state, dayNight:'night', detail:'ultra', height:'standard', reducedMotion:runtime.reducedMotion })
const defs = ensureDefs(svg)
runtime.start((dt, elapsed) => { defs.tick(elapsed, runtime.reducedMotion); scene.tick(dt, elapsed) })
window.stopWorkfloorBench = () => { runtime.destroy(); scene.destroy(); removeDefs(svg); svg.remove() }
```

## 新增世界清单

1. 先经新的设计工单明确构图、状态映射和施工面；不要在现有世界的收尾单里新增世界或设置。
