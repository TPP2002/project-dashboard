# 工单 M3 · 发射场 v10 质感返工（透视 / 光束 / 加注车 / 火箭对接 / 排气 / 闪电 / 火焰烟雾碎霜）

> 关联卡 AUD-FUN-WORKFLOOR · 派单 slug `aud-fun-m3-launch-fx` · 施工面只有一个文件：`docs/mockups/外观个性化-mockup-v10-2D插画发射场.html`
> 负责人看了 v10 后的原话："透视关系有问题；灯塔那个光束有很大问题，不像光束；卡车不会掉头；火箭和支架对接有问题；阻塞时火箭右侧的白条是啥？雾气？不够液态化，没有气体的感觉；闪电光影不对；点火的火焰没有火焰质感，烟雾和碎霜也太敷衍了。我是细节狂魔，我很在意这些细节和呈现的质感。"
> 这一单**不加新东西，只把这七处做到有质感**。每一处都给了做法，照做；做完的效果要经得起放大 200% 看。

## 0. 总则

1. 每个特效写成**可复用的函数**（`fxBeam / fxVent / fxFlame / fxSmoke / fxFrost / fxLightning / fxTruck`），输入锚点与参数，输出 SVG 片段 + 每帧更新函数。后面接进看板页要原样搬走，所以别和场景代码搅在一起。
2. 特效的"质感"来自**分层 + 软边 + 受光**：任何一团火、烟、雾、光都至少三层（核心 / 中间 / 外晕），软边用 `feGaussianBlur`，形状扰动用 `feTurbulence + feDisplacementMap`，并且要**照亮周围**（火照地面和烟、闪电照塔、光束照海面）。一层平涂的多边形一律不合格。
3. 性能：滤镜只挂在小元素上（一团火、一道闪电、一条光束），不挂全屏；粒子封顶写死；`prefers-reduced-motion` 下特效直接出最终态、不逐帧。
4. 画法仍是 v9 那套赛璐璐（基色渐变 + 高光棱线 + 硬阴影面 + 深色线稿）；特效层是"光"，不描线。

## 1. 透视关系（负责人："透视关系有问题"）

**病根**：现在 VAB 是从左前方看（露左侧面），指挥中心却露右侧面，塔、发射墩、集装箱又是纯正面，各画各的。

**定死一种投影：相机在左前上方的斜投影（cabinet）**——所有盒子都是"正面矩形 + 左侧面向左上方后退 30°、进深 = 宽的 0.45 + 顶面薄薄一片"。逐个改：

| 对象 | 要求 |
|---|---|
| VAB | 保持现状（正面是大门与门内火箭，左侧面写 VAB）；顶面 RGB 灯带沿顶面前缘走。 |
| 指挥中心 | 侧面翻到**左边**（"LAUNCH CONTROL" 竖字随之搬到左侧面），屋顶大屏正面朝前。 |
| 发射墩 / 火焰导流槽 | 墩体露左侧面与顶面；导流槽开口朝右（朝海），槽口在顶面上能看见。 |
| 勤务塔 | 桁架露正面 + 左侧面两片格构（左侧面按 30° 后退画成平行四边形），平台同理有薄厚度。 |
| 集装箱、工具箱、纪念柱、防波堤石块、灯塔底座 | 全部露左侧面。 |
| 履带路 | 从 VAB 大门口先朝画面**前方**（向下）出来 24px，再以一段圆弧向右拐，之后沿 x 轴向右到发射墩；路是一条 SVG path，履带车沿 `getPointAtLength` 走（拐弯时车头朝向跟着切线转）。 |
| 地面 | 场坪接缝网格改成和投影一致：横线水平、"纵"线向左上 30° 后退；灯杆、旗杆竖直不变。 |
| 前后关系 | 越靠画面下方越近：VAB 底边 ≈ 400，指挥中心 ≈ 400，发射墩 ≈ 420，前景护栏/叉车 ≈ 470~500。近处物体略大（前景集装箱比远处的大 15%）。 |
| 光影 | 月亮在右上：所有物体的硬阴影面在**左侧面与底部**，地面投影朝左下；探照灯是局部光池，只照它锥体覆盖的地面。 |

判据：把画面里任意两个盒子并排看，侧面朝同一个方向、同一个角度；路和车的走向说得通。

## 2. 灯塔光束（负责人："不像光束"）

现状是一片平涂的半透明楔形。改成：

1. **两层楔形**：内层半角 5°、长 420px，沿长度方向线性渐变（源头白 .55 → 末端透明），`feGaussianBlur` 2.5；外层半角 12°、长 380px、不透明度 .12、`feGaussianBlur` 8（这是空气里的体积感）。两层都从灯室中心出发。
2. **旋转**：整组以灯室为原点每 9 秒转一圈（CSS rotate，线性）；不透明度按朝向调：朝向观众（向下）时最亮、朝向画面深处（向上）时降到 25%——JS 每帧 `opacity = .25 + .75 * max(0, cos(angle − 90°))`。
3. **灯室**：一枚径向渐变光斑（白 → 淡黄 → 透明，r 14）随光束同步呼吸；灯室玻璃本身画出竖棂。
4. **照到东西**：光束扫过海面时，海面上出现一片沿光束投影方向的柔边亮斑（椭圆，不透明度 .18，随光束角度移动、只在海面 clipPath 内）；扫过防波堤时堤顶石块的顶面短暂提亮（叠一层白 .15）。
5. **遮挡**：光束画在灯塔塔身之前、塔身之后各一层？不——光束整组画在灯塔**之后**，塔身盖住光束根部；不许光束穿塔而过。

判据：截 3 帧不同角度，能看出它是一束在空气里扫的光，不是一块贴上去的三角形。

## 3. 加注车（负责人："卡车不会掉头"）

现状是同一朝向左右滑动。改成：

1. 车走一条固定 path：储罐区加注口 ↔ 发射墩燃料接口，`getPointAtLength` 取位置，**车头朝向 = 切线方向**。
2. 到端点停 600ms：刹车灯亮（红），加注臂伸出 / 收回（一根小杆 300ms）。
3. **掉头**：用 3 步把 `scaleX` 从 1 → .25 → −1（各 120ms），车厢同时略微转向（rotate ±6°），车顶黄色警示灯常闪。
4. 车轮：两个轮子画轮辐，按位移旋转；车头灯：一枚朝行驶方向的柔边光锥（不透明度 .12）。
5. 只在 FUEL 阶段跑；ROLLOUT / HOLD / SCRUB 停在储罐区；起飞前 2 秒必须已回到储罐区（安全距离）。

## 4. 火箭与支架对接（负责人："火箭和支架对接有问题"）

现状火箭浮在塔旁，摆臂够不到，固定夹位置不对。定死几何常数，其余按常数画：

```
PAD_X        火箭中轴 x
MOUNT_TOP    发射台桌面 y（= 发动机喷口底 + 4px 支座）
BODY_R       箭体半径（13）
TOWER_X      塔中轴 x = PAD_X − 78
ARM1_Y       燃料臂高度 = 级间段黑带中点 y
ARM2_Y       乘员臂高度 = 整流罩底缘上方 10px
```

1. **发射台**：桌面是一块有厚度的平台（顶面 + 左侧面），中央开口正对导流槽；四个固定夹在桌面四角（前两个可见、后两个露一半），**合拢时压在一级底部的加宽法兰上**（一级底部要画一圈比箭体宽 3px 的法兰环）；张开时向外翻 35°。
2. **摆臂**：从塔身向右伸，臂根有铰链座；燃料臂末端是一块耦合板，合上时**贴平箭体左侧**（x = PAD_X − BODY_R），板上两根软管垂下；乘员臂末端是一间小舱，贴在整流罩底缘下方。臂长 = TOWER_X + 16 到 PAD_X − BODY_R，一个像素不多不少。
3. **转运到位**：履带车停在 PAD_X 正下方（火箭中轴对齐），然后 600ms "落座"（火箭随车台下降 6px 到 MOUNT_TOP），固定夹合拢（300ms），摆臂各自摆过来贴上（400ms，绕铰链旋转，不是平移），最后履带车倒退 60px 停在台左侧（倒车时车尾黄灯闪）。
4. **起飞**：T-0 点火 → 0.4s 内摆臂绕铰链向左摆开 60°、固定夹翻开 → 火箭开始上升（前 1 秒只升 30px，然后加速）→ 出画。摆臂摆开后停在张开位，下一枚到位时再合上。
5. 特写画面用同一套常数，放大后对接处必须严丝合缝。

## 5. 排气 / 白雾（负责人："白条是啥？不够液态化，没有气体的感觉"）

现状是箭体旁一根白条。改成 `fxVent`：

1. 箭体两侧各两个排气口（级间段下沿、一级上部），口子本身画出来（小圆管 + 深色口）。
2. 每 350ms 从每个口冒一团：一团 = 3 个错位叠放的软椭圆（径向渐变 白 .8 → 透明，`feGaussianBlur` 3），初始缩放 .3，2.6 秒内长到 1.6 倍，**向下沉并向外飘**（液氧排气是冷的，往下走），横向按 `sin` 轻轻摆，不透明度 .7 → 0。
3. 口子附近常驻一小段细的雾丝（短的模糊描边）锚定来源；箭体在排气口周围 20px 内有一圈淡淡的白色结霜环。
4. 排气频率与浓度随 FUEL% 增加（0% 无，100% 每口 250ms 一团）；HOLD 时继续，SCRUB 时雨里照冒；起飞时随火箭一起走并在 1 秒内散掉。
5. 判据：截一帧能看出是一团团正在往下沉、正在散开的气，不是贴在箭体上的白条。

## 6. 闪电（负责人："光影不对"）

现状是一根线。改成 `fxLightning`：

1. HOLD / SCRUB 阶段先在发射台上空画出**一朵积雨云**（层叠深灰团块，顶部受月光略亮，底部更暗），闪电从云底出发。
2. 主通道：云底到避雷针尖，12~14 段折线，横向随机偏移 ±14px、越接近针尖越小；2~3 条分叉从中段分出，长度 30~50%、不透明度 .6。
3. 三层描边：外晕（#8fd3ff，宽 8，`feGaussianBlur` 6，不透明度 .55）、中层（#e6f7ff，宽 3）、芯（#fff，宽 1.4）。
4. **光影序列（约 420ms）**：t0 通道亮 + 针尖处爆闪（径向渐变圆 r 90，白 → #8fd3ff → 透明，不透明度 .9）+ 云底被照亮（云的下缘叠一层蓝白 .35）+ **塔与火箭被照亮**（用塔和火箭的剪影做 clipPath，叠白 .35，只照朝向闪电的那一侧，另一侧不变）+ 地面在塔脚出现一圈蓝白反光；t0+60ms 全灭；t0+110ms 通道重随机再亮一次（.8）；t0+180ms 灭；爆闪 250ms 内淡出；针尖残留一点蓝光 1.5 秒。
5. 天空只在云周围 200px 范围变亮（柔边椭圆 .3），**不许全屏闪**。

## 7. 点火：火焰 / 烟雾 / 碎霜（负责人："没有火焰质感，烟雾和碎霜太敷衍"）

### 7.1 `fxFlame`
1. 三层 + 冲击菱：芯（白 → #ffe9a8，长 L、宽 w）、幔（#ffb347 → #ff6a00，长 1.3L、宽 1.5w、不透明度 .85）、外晕（#ff4d1a → 透明，长 1.6L、宽 2.2w、不透明度 .5）；芯上沿轴线 0.2L/0.4L/0.6L/0.8L 放 4 枚白色椭圆冲击菱，尺寸递减。三台发动机各一束，中间那束略长。
2. 整组挂 `feTurbulence(fractalNoise, baseFrequency .04 .12, numOctaves 2) + feDisplacementMap(scale 6)` 做边缘扰动，用 SMIL `<animate attributeName="seed">` 或每帧改 `baseFrequency` 让它活起来；JS 每帧再给 scaleY 加 ±12%、scaleX ±8% 的抖动，冲击菱不透明度随机闪。
3. 喷口处一枚大的橙色柔光（径向渐变，`feGaussianBlur` 8，不透明度 .5）。
4. **照亮周围**：地面一片橙色径向光（不透明度 .35，随火箭升高衰减）；发射台、塔的下半段、固定夹叠一层橙色（clipPath 到它们的剪影，不透明度 .25，同样随高度衰减）；烟团在火箭高度 < 120px 时**下半边是橙色**（见 7.2）。
5. 火焰长度随上升变长（L 从 60 → 110），出画前收成细长的一线。

### 7.2 `fxSmoke`
1. 一团 = 主圆（径向渐变：心 #d9dde6 .9 → 中 #9aa3b3 .6 → 边透明）+ 右下错位一枚更暗的圆（体积阴影）+ 左上一小枚更亮的圆（月光高光）；火箭还在低空时，主圆下半叠一枚橙色径向（火光）。
2. 点火后前 0.8 秒每帧从导流槽两侧出口各喷 2 团，初速向外（vx ±2.5，朝海那侧 ×1.4）、略向上（vy −0.6）；**先贴地向两侧滚**（前 1 秒 y 几乎不变），再上升；缩放 1 → 4（3 秒），2.5 秒后开始淡出，总寿命 5~7 秒；横向被风往海那边带（加速度 +0.02/帧）；用 `sin/cos` 噪声让每团轻微摇摆。
3. 封顶 70 团；画序：大的、老的在后，小的、新的在前。
4. 起飞后 4 秒烟散尽，地面留一片淡淡的灰痕 6 秒后消失。

### 7.3 `fxFrost`
1. 点火瞬间沿一级箭体下 40% 段生成 24 片碎霜：每片是 4~5 个顶点的不规则小多边形（半径 2~4px），白色带一点淡蓝，不透明度 .9。
2. 运动：初速横向随机 ±1.2，重力 +0.25/帧，阻力 .98，自转每帧 3~8°；落到发射台面弹一次（vy × −0.3）再淡出；落进火焰区的立刻消失。
3. 在箭体上原本就有的结霜层（随 FUEL% 涨的白色竖条）要**真的剥落**：碎霜掉下后箭体上的结霜层减薄。

## 8. 特写画面

特写用同一套函数，四个模式里：加注 60% 要看到排气团在往下沉；HOLD 要看到云、闪电和被照亮的塔面；点火要看到三层火焰 + 冲击菱 + 橙光照亮台面 + 烟团 + 碎霜翻滚。

## 9. 验收

- A1 `test:targeted test/noLocalIdentifiers.test.cjs`。
- M1 人工（派单方渲染核图）：①任意两个盒子侧面同向；履带路带拐弯、车头随切线转；②光束三帧不同角度 + 海面亮斑；③加注车在端点掉头、刹车灯、车轮转；④火箭落座后固定夹压法兰、摆臂贴体、起飞时绕铰链摆开；⑤排气团往下沉、散开；⑥闪电三层 + 塔面被照亮 + 不全屏闪；⑦火焰三层 + 冲击菱 + 地面橙光，烟先滚后升且朝海飘，碎霜翻滚坠落弹起；⑧特写四态同样过关；⑨200% 放大看边缘全是软的、没有一层平涂。
- 你的沙箱没有浏览器：`new Function` 编译 `<script>` 段确认无语法错误；`summary` 按七处逐条写"怎么做的、为什么这样有质感"。

## 10. 不许做的

- 不改 v9；不改七个按钮与状态机语义；不加新场景元素（这一单是把已有的做对做细）。
- 不用位图、外部资源、emoji；不出现本机路径、主机名、其他项目名。
- 做不到的写 `openQuestions`，别降级糊弄——负责人一眼就看得出来。
