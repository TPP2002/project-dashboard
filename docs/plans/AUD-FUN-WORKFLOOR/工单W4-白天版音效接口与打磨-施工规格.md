## 1. 白天版（总契约 §8）

1. `web/src/workfloor/daynight.ts`（纯函数，不 import vue/dom）：`resolveDayNight(setting: 'theme'|'night'|'clock', theme: 'light'|'dark', hour: number): 'day'|'night'`——`theme`：浅色 = day；`clock`：6 ≤ hour < 18 为 day；`night`：永远 night。`test/workfloorDayNight.test.cjs` 覆盖三种设置 × 边界小时（写法照 `test/workfloorBridge.test.cjs`）。
2. `WorkFloor.vue`：按 `appearance.workfloor.dayNight` + `web/src/utils/theme.ts` 的实际主题 + 本机小时算出 day/night，调用 `handle.setDayNight()`；`clock` 模式每分钟重算一次；主题切换即时生效。
3. **机甲白天调色板**（`scenes/mech/palette.ts`）：大门敞开、门外天光（暖白 → 青灰的渐变从门口洒进来，地面一道亮区）、泛光灯关（光锥隐藏）、墙面与地面整体提亮两档、全息投影更淡、焊接弧光与火花对比反而更强；控制台屏幕不变。
4. **发射场白天调色板**（`scenes/launch/palette.ts`）：晴空（天空蓝 → 地平线暖白、云更白更实、星月隐藏、太阳在右上带柔光）、海更蓝带白色碎光、探照灯/路灯/灯塔光束隐藏（灯体保留）、指挥中心窗户不发光、VAB 门内顶灯仍亮但对比弱、点火火光对比减弱、烟更白更显眼；倒影按白天天色。
5. 切换昼夜时 600ms 过渡（调色板变量插值或淡入淡出二选一，不许闪一下）。

## 2. 行为修正（派单方核 W2/W3 时发现）

1. **机甲大屏状态优先级**：`complete` → POWER ON；否则有 `pending` → INSPECT?；否则有 `active` → WELDING <部件>；否则有 `blocked` → JAMMED；否则 STANDBY。现在只要有暂缓卡就常显 JAMMED、警灯常亮——改成：警灯 + 红色洗光只在 `block` **事件**时闪 2.6 秒；暂缓的部件常态是红色描边（不闪）。
2. **发射场转运期间大屏显示 ROLLOUT**（现在显示 FUEL 0），落座夹合后才切 FUEL nn。
3. **起飞 / 扣上动画不得被状态刷新截断**：`done` 事件与随后到达的 `update(state)` 几乎同帧——场景必须把正在起飞的火箭（机甲：正在白闪的部件）放进"进行中的动画"队列，`update()` 不许移除它们，动画结束后再按状态整理。请写一个专门的单测不了的说明进开发说明，并在 `bench` 测试台加一个"连发 done + update"的按钮用来人工复现。
4. **同一秒多张完工只播一次**（总契约 §5.2）核一遍两个场景都做了；没做补上。
5. **首帧不重放**核一遍：刷新页面时不许出现转运/焊接动画从头播。

## 3. 音效联动接口（总契约 §3 `soundLink`）

1. `types.ts` 的场景上下文加 `sound?: (cue: SoundCue) => void`，`SoundCue = 'weld' | 'stamp' | 'alarm' | 'done' | 'ignition' | 'liftoff' | 'complete' | 'hold'`；两个场景在对应动作处调用（机甲：焊接开始 weld、盖章 stamp、卡件 alarm、扣上 done、通电 complete、挂检验 hold；发射场：点火 ignition、离台 liftoff、HOLD hold、SCRUB alarm、MISSION COMPLETE complete、GO stamp）。
2. `WorkFloor.vue`：`soundLink && appearance.sound` 时把 cue 交给 `web/src/utils/sound.ts` 的 `playSound(cue)`——**该模块尚不存在**（提示音功能另一张工单），本单只做：`import type` 级别的接口 + 运行时 `try { (await import('@/utils/sound')).playSound(cue) } catch {}` 这种存在即用、不存在即静默的接法（打包不能因为模块不存在而失败：用 `import.meta.glob` 或先判断，自己选一种能过 vite build 的写法）。
3. 静音时段与音量由 sound 模块自己管，本单不管。

## 4. 质感打磨（对照 `质感标准.md` §3 与 `质感样张-v1.html`）

1. 发射场光束：在场景里仍偏细偏淡——按样张 04 格参数（内层半角 5° 长 420、外层 12°、源头 .55 衰减到 0、朝向亮度）调到位；扫海亮斑要看得见。
2. 发射场烟：确认用的是程序化云（噪声蒙版 + 位移 + 明暗层错位 + 火光染底），不是软圆；起飞后 4 秒散尽。
3. 机甲焊接：火花溅落弹一次、弧光照亮周围装甲（clipPath 到相邻部件叠白 .25，随弧光闪）。
4. 两个场景的"紧凑档"裁切：主体（机甲全身 / 火箭 + 塔）必须完整在 1400:360 内，大屏可以被裁一部分。
