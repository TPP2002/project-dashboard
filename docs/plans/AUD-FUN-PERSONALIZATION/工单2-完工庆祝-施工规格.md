## 1. 新文件 `web/src/utils/boardEvents.ts` —— 看板事件总线

```ts
export type BoardEventKind = 'claim' | 'progress' | 'pending' | 'decide' | 'done' | 'park' | 'block' | 'note'
export interface BoardEvent { kind: BoardEventKind; projectId: string; taskId: string; ts: string }
export function onBoardEvent(fn: (e: BoardEvent) => void): () => void   // 返回退订函数
export function emitBoardEvent(e: BoardEvent): void
```
- 纯函数模块，不引 Vue。订阅者集合用 Set；`emit` 里对每个订阅者 try/catch，一个订阅者抛错不影响别的。
- **谁来 emit**：`stores/board.ts` 现有的 `diffPulse(pid, oldBoard, newBoard)`——它已经在算「这次刷新新增了哪些活动」。在它给 `markPulse` 的同一个循环里，对每条新增活动 `a` 且 `a.taskId` 存在时 `emitBoardEvent({ kind: a.type as BoardEventKind, projectId: pid, taskId: a.taskId, ts: a.ts })`。`activityKind()` 认不出的 type 照样发（kind 为原始字符串），订阅者自己判断。**首次加载（oldBoard 为空）不发**——那不是「刚发生的事」。
- 顺手把「事件」与「卡片元素」的登记也放这个文件：
```ts
export function registerCardElement(key: string, el: HTMLElement): void
export function unregisterCardElement(key: string, el: HTMLElement): void   // 只有当前登记的是这个 el 才删
export function findCardElement(key: string): HTMLElement | null           // key = `${projectId}:${taskId}`
```

## 2. 新文件 `web/src/utils/confetti.ts` —— 彩带（canvas 逐帧自绘，无依赖）

```ts
export function burstConfettiAt(rect: DOMRect, opts: { count: number; colors: string[] }): void
```
- 在 `document.body` 上追加一个 `position: fixed` 的 canvas，`left/top/width/height` 取 rect，`pointer-events: none`，`z-index` 高于抽屉与面板（用 90）。**画在覆盖层而不是卡片里**：完工的卡会在下一次渲染时从泳道消失（已完工泳道默认收起），画在卡里会跟着一起没。
- `devicePixelRatio` 缩放；`count` 个小矩形（宽 4~9、高 2.5~6.5），从矩形下沿 55% 高度、水平 30%~70% 处向上炸开（`vy` -3.2~-8.4，`vx` ±3.5，重力 .34，横向阻尼 .992，各自旋转），总时长 1200ms，最后 35% 渐隐；结束后移除 canvas。
- `colors`：调用方传；本单从 `utils/spectrum.ts` 已有的 `readStops('--spec-active')` 取（再 `openCycle` 去掉收尾重复色）。
- `prefers-reduced-motion: reduce`（用 `utils/iconMotion.ts` 已导出的 `reducedMotion.value`）时直接 return，什么都不画。

## 3. 新文件 `web/src/utils/celebrate.ts` —— 把事件接到效果上

- 模块加载时 `onBoardEvent` 订阅；只处理 `kind === 'done'`。
- 规则：①`appearance.confetti` 为 false → 不放；②`findCardElement(`${projectId}:${taskId}`)` 找不到（不在看板页 / 卡在收起的泳道里 / 不在视口内——用 `getBoundingClientRect()` 判断有交集）→ 不放，不补放；③**一秒内只放一次**（记上次放的时刻，1000ms 内再来的 done 只加数不放）；④放：`burstConfettiAt(rect, { count: appearance.confettiCount, colors })`。
- 在 `main.ts` 或 `App.vue` 里 import 一次让它生效（只 import，不调用）。放在 `App.vue` 顶部 `import '@/utils/celebrate'` 即可。

## 5. `web/src/utils/derive.ts` —— 连击宽限
现有：
```ts
export function doneStreak(byDay: Map<string, DoneRecord[]>): number {
  const d = new Date()
  if (!byDay.get(localDay(d))?.length) d.setDate(d.getDate() - 1)
  let streak = 0
  while (byDay.get(localDay(d))?.length) { streak++; d.setDate(d.getDate() - 1) }
  return streak
}
```
改成 `doneStreak(byDay, grace = false)`：
- `grace = false` 时行为**逐字节不变**（老调用方不受影响）。
- `grace = true` 时：起点规则不变（今天没产出就从昨天起算）；往前走时遇到空的一天，**看再前一天**：再前一天有产出 → 这个空天也算进连击（`streak++`）继续往前；再前一天也空 → 停（空天不算）。**连着两个空天才断；单个空天算进天数**（d2 拍板）。起点那天（今天或昨天）本身必须有产出，否则连击为 0——不改这条。
- 函数头注释写清两种规则各是什么、为什么（拍板出处 d2）。

## 8. 已知坑
- `stores/board.ts` 的 `loadBoard` 先赋值 `boards.value` 再 `diffPulse`，事件发出时旧卡元素还在 DOM 里，这正是能在原地撒彩带的原因；**别把 emit 挪到赋值之前或之后的 nextTick 里**。
