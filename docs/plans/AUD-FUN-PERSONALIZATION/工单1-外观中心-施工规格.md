## 0. 一句话

顶栏「外观」下拉精简成四样常用，底部一行「全部外观设置」打开一张居中大面板（七个分类）；本单落地其中「灯条与动效」「密度与字号」两类的**效果**，其余五类只做**设置控件与存档字段**。默认值下界面与现在逐像素一致。

## 1. 新文件 `web/src/utils/appearance.ts`（照 `utils/spectrum.ts` 的写法）

- `export const appearance = reactive<AppearanceConfig>({...})`，`version: 1`，字段与默认值：

| 字段 | 类型 | 默认 | 落到哪 |
|---|---|---|---|
| `speed` | `'slow' \| 'normal' \| 'fast'` | `'normal'` | `:root` 内联 `--sp-k`：slow=1.55 / normal=1 / fast=.62 |
| `glow` | `'thin' \| 'normal' \| 'thick'` | `'normal'` | `--gl-k`：.65 / 1 / 1.5；同时 `--gl-op`：.82 / 1 / 1 |
| `edgeBreathe` | `boolean` | `false` | `document.documentElement.dataset.edge = 'breathe' \| 'flow'` |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | `--dens`：1 / .75 |
| `fontSize` | `13 \| 14 \| 15 \| 16` | `14` | `--fs`：`${n}px` |
| `confetti` | `boolean` | `true` | 本单只存 |
| `confettiDensity` | `'low' \| 'mid' \| 'high'` | `'mid'` | 本单只存 |
| `streakFire` | `boolean` | `true` | 本单只存 |
| `streakGrace` | `boolean` | `true` | 本单只存 |
| `projectColor` | `boolean` | `true` | 本单只存 |
| `projectMark` | `'icon' \| 'letter'` | `'icon'` | 本单只存 |
| `ringMode` | `'projectFlow' \| 'globalFlow' \| 'projectSolid'` | `'projectFlow'` | 本单只存 |
| `projectOverrides` | `Record<string, string>`（项目 id → `#rrggbb`） | `{}` | 本单只存 |
| `sound` | `boolean` | `false` | 本单只存 |
| `soundVolume` | `number` 0~1 | `.35` | 本单只存 |
| `quietFrom` / `quietTo` | `'HH:MM'` | `'22:30'` / `'08:30'` | 本单只存 |
| `wireEvents` | `{ done: boolean; pending: boolean; block: boolean }` | 全 `true` | 本单只存 |

- localStorage 键 `board-appearance`。`loadConfig()` 逐字段校验：枚举不在集合内、数字不在范围内、颜色不匹配 `^#[0-9a-fA-F]{6}$`、时间不匹配 `^\d{2}:\d{2}$` 的一律丢弃回默认；存档损坏当没存过。
- `applyAppearance(persistNow = true)`：把上表「落到哪」那几项写进 `:root`；**默认值时删掉内联变量而不是写默认值**（与 spectrum 一致：删掉 = 回落 base.css）。
- 每个字段一个 setter（`setSpeed(v)` 等）或一个 `patchAppearance(partial)`，setter 内部调 `applyAppearance()`。
- `resetAppearance()`：全部回默认并落地（大面板底部「全部恢复默认」用；**只重置 appearance，不重置 spectrum 与 iconMotion** —— 那两处各有自己的默认按钮语义，不在本单）。
- 模块加载即 `loadConfig()` + `applyAppearance(false)`（与 spectrum.ts 末尾那段一样，避免首屏闪）。
- `export function playSound(kind: 'ding' | 'dong' | 'low'): void {}` 先做空实现（带注释：后续单接 WebAudio），提示音页的「试听」按钮调它。

### 3.1 令牌改成可缩放（**默认值下算出来必须与现在一字不差**）

```css

--s1: calc(4px * var(--dens)); --s2: calc(8px * var(--dens)); --s3: calc(12px * var(--dens));
--s4: calc(16px * var(--dens)); --s5: calc(24px * var(--dens)); --s6: calc(32px * var(--dens)); --s7: calc(48px * var(--dens));

--fs-xs: calc(var(--fs) * .786); --fs-sm: calc(var(--fs) * .893); --fs-base: var(--fs);
--fs-md: calc(var(--fs) * 1.071); --fs-lg: calc(var(--fs) * 1.286); --fs-xl: calc(var(--fs) * 1.571); --fs-2xl: calc(var(--fs) * 2);
```

### 3.2 灯条速度与粗细
```css
--sp-k: 1; --sp-base: calc(3.4s * var(--sp-k));
--gl-k: 1; --gl-top: calc(2px * var(--gl-k)); --gl-rail: calc(6px * var(--gl-k)); --gl-edge: calc(2px * var(--gl-k)); --gl-op: 1;
```
`.glow`（animation 时长→`var(--sp-base)`、`opacity: var(--gl-op)`）、`.glow-top`（高度→`var(--gl-top)`，圆角随之）、`.glow-rail, .progress`（高度→`var(--gl-rail)`）、`.glow-rail > i, .progress > i`（时长、opacity）、`.glow-edge`（宽度→`var(--gl-edge)`，时长、opacity）。`.spectrum-swatch` 的流动（若有）同理。

### 3.3 施工中竖条呼吸


## 11. 已知坑
- 施工工作区里 `web/node_modules` 是指向主工位的目录联接，沙箱写不进去，`vue-tsc`/`vite` 你自己起不来——不要试，派单器会跑。
- `--fs-*` 改成 calc 后，凡是用 `--fs-xs` 参与再计算的地方（如 `calc(var(--fs-xs) * 2)`）仍合法；但 **canvas/echarts 读 `getComputedStyle` 拿字号的地方**（`views/DailyOutput.vue` 等，本单禁区）拿到的是解析后的 px 值，不受影响。
- `--s*` 改成 calc 后，凡是把它当 `calc()` 里的项用的地方仍合法；但 CSS 里写 `-var(--s2)` 这种负值写法（若有）要检查是不是 `calc(-1 * var(--s2))`。
- 主题模块搬家时，`TopBar.vue` 顶部那段「模块一加载就还原主题」的副作用必须保留（挪到 theme.ts 顶层），否则首屏闪主题。
