# 对话成本归属施工记录

## 目标与既有问题

成本页原先把会话工作目录的某一段与卡号精确比较。实际会话目录常是仓库根或带随机后缀的工位，因此明细大量显示“未判定”。本次按已定的绑定、分支、命令文本三级证据判卡；多卡与歧义分别显示，未命中则保留未归因。

## 逐步施工

1. 新建零依赖的共用纯函数判据及单测。固定版本、主干清单、绑定文件名和七个导出；测试覆盖主干排除、独占和共享分支、绑定优先、命令提取、坏绑定行与零依赖。
2. 新建绑定文件读写层。仅接受有效会话编号，重复的会话加卡号不追加；文件不存在读为空字典，其他读写错误向调用方抛出。
3. 在认领和收官的看板写入成功后记录绑定。绑定失败只向错误输出写警告，不改两条命令的返回结构。新增绑定单测，并定向检查原有命令输出测试。
4. 扫描器在原预筛上增加命令文本，收集每个会话的分支、认领卡号和分支参数；跨文件取并集。缓存版本升到 4。明细行使用共用判据，筛选、选项和合计按归属字段处理，保留旧测试手写行的兼容路径。已删除按工作目录判卡的旧用例，其余既有断言保留；旧缓存版本断言改为 4。
5. 成本接口读取卡号加分支及绑定；只在两处会话用量调用中传入，组合总览调用不变。
6. 对话明细的卡列显示一张卡、多卡、歧义、未归因；筛选条下显示四类计数。歧义只提供候选提示，不提供打开卡按钮。
7. 新建只读对读工具。新旧代码各用独立临时缓存，对同一流水比较会话数、判卡比例和固定抽样，结束清理临时缓存。
8. 只在快速测试的文件清单尾部加入两份新测试。
9. 完成本记录。

## 建议与边界

C 级措辞和“先建分支到命中卡映射再判”的建议均未推翻。分支级先汇总每个有命中的分支，再判独占、多卡或歧义。没有加入目录名、时间或比例猜测，也没有补历史绑定。

## 给收单方

本工作区只做定向自查，不运行快速全套、类型检查或构建。请按施工单统一重跑，并在私有仓保存真实流水对读原文、逐条抽样核对和界面截图；公开仓只保留汇总计数。发布后需在真实会话中验证绑定文件新增行。最终合并、发布与看板销卡由收单方执行。
