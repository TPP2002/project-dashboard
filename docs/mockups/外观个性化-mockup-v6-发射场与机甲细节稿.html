02机甲装配

你要的「类似发射场的进度指示」，我没有硬塞一根进度条，而是拆成三处各管一件事：焊缝（这张卡进到几成：正在焊的那块部件，亮色焊缝沿轮廓一圈圈合上，进度 100% 焊缝闭合、部件扣入）、机库大屏（这个项目到几成：一块机甲剪影从脚到头填色，旁边像素字 ASSEMBLY 64%，还有当前状态 WELDING / INSPECT? / JAMMED / POWER ON）、胸口核心充能环（离通电还有多远：项目越接近 100%，核心那圈弧段亮得越多，满了就通电）。三处对应发射场的液位表、大屏、倒计时——同一套语言，不同的形。

画面分层与物件细节清单（施工下限）

机库背墙钢板带铆钉与接缝线、左上巨大的「BAY 02」喷涂字、顶部主梁与两条管道（带阀门、隔段一个压力表）、两层检修走道（栏杆、楼梯）、四盏泛光灯（光锥照在机甲上、夜里更亮）、顶部与地沿各一条你的配色灯带、地沿黄黑警示条纹、垂下来的电缆随空气微晃、墙上一块「机库大屏」。
机库大屏左：机甲剪影进度（从脚到头填色，填色边缘有一条亮线）；右上：ASSEMBLY 64% 像素字；右下状态：WELDING ARM-R（青）/ INSPECT?（琥珀闪）/ JAMMED（红闪）/ POWER ON（你的配色流光）；底部 PARTS 14/22。
零件架三层货架、每格一个部件的小剪影（腿是腿、臂是臂）+ 部件编号小字；架子旁一台小型行车吊着一块备件；取走的格子变空、留下一个轮廓虚线。
机甲（56×96 像素）装甲板分块、每块有面板线与铆钉、肩甲上项目色徽章与红条、头部面罩与下巴、胸口核心与充能环（八段弧）、腹部关节线、膝盖液压杆（两色）、脚踝、背包推进器（两个喷口）；未装的部件是虚线轮廓；已装的部件受泛光灯照有明暗两面；脚踩在水里，水面有泡沫线。
无人机（9×5）机身两色、两副螺旋桨（两帧模糊）、下方机械爪；取件时爪子夹着部件的小剪影；焊接时机身向下倾、焊枪伸出；弧光：白色高频闪 + 黄橙火花往下溅并弹一次；弧光把附近装甲照亮（周围两像素变亮两帧）。
焊缝（卡的进度）正在焊的部件：一条亮色焊缝从左上角沿轮廓顺时针延伸，长度 = 进度百分比；焊缝末端就是无人机焊枪停的位置；100% 闭合时白光一闪、部件实心填色、该块「咔哒」抖一像素两帧、水面荡一圈涟漪。
检验单（待拍板）部件上方垂一根小钩线挂着一张琥珀色标签，写「?」，轻轻摆；无人机退开半步悬停；大屏 INSPECT?；地沿灯带转琥珀。盖章（拍板）：标签上「盖」一个绿章、飞走，焊缝继续。
卡件（阻塞）部件轮廓红闪、墙上红色旋转警灯扫过整个机库、无人机退到安全距离、大屏 JAMMED；解除后回到 WELDING。
通电（项目 100%）逐帧最后一块扣入 → 核心充能环最后一段亮 → 泛光灯暗下去一半 → 核心你的配色流光 → 眼睛亮（两帧由暗到亮）→ 关节喷蒸汽 → 右臂缓缓抬起 → 大屏 POWER ON → 水面倒影随灯光跳动。通电后的整机移到船坞后排列队（多项目各一台、机型不同），下一台从空轮廓开始。

03白天版

两个世界都有白天：发射场白天是海边晴空（云更白、海更蓝、灯不亮、烟更显眼、点火时火光对比弱一些）；机库白天是大门敞开、外面天光照进来、泛光灯关、焊接弧光反而更抢眼。顶部按钮「白天」能切上面两块画面看。
