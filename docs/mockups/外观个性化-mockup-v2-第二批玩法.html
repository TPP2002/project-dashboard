02城与天 主推 · 原创

一句话：每个项目是一栋楼，每张卡是一扇窗，天空是板子的心情。 楼从下往上亮：完工的窗是暖黄的灯，正在施工的窗在跑 RGB 流光，等你拍板的窗琥珀色一闪一闪，卡住的窗红着，没开工的窗黑着——所以一栋楼就是一块缩小的看板， 而且它会随着你几个月的产出一层一层亮上去。天空只讲一件事：用不用你。没人等你就是晴夜、有极光（用你选的灯条配色）； 有卡等你拍板，云就来了，新来一条会打一道琥珀色的闪；有卡卡住了就下雨；一个项目全部完工，楼顶尖塔亮起来放烟花。

完工的窗 施工中（流光） 待拍板（闪） 阻塞 暂缓 没开工 塔吊 = 楼上有人在施工　·　屋顶小灯 = 有事等你（琥珀）/ 有卡卡住（红）　·　尖塔 = 100%
板子上发生什么城里 / 天上怎么变
有卡在施工中那扇窗跑流光；楼顶立塔吊，吊臂慢慢摆。走的是你在外观里选的配色和速度。
来了一条待拍板云飘过来（越多越厚），当下打一道琥珀色的闪；那扇窗开始一闪一闪；屋顶亮琥珀小灯。
你拍掉了云散一朵；窗变成暖黄。云全散了极光就回来。
有卡阻塞下雨；那扇窗红着；屋顶亮红灯。解除就停雨。
一张卡完工那扇窗白光一闪，落成暖黄，楼长高了一格。
项目 100%尖塔亮起，楼顶放三轮烟花（只放这一次，记在本机）。
点某栋楼顶栏切到那个项目。当前项目的楼描一圈蓝边，别的楼略暗。
为什么它比小人有意思。小人在工位上打字，看一分钟就知道它在打字；而这座城是你自己的产出堆出来的—— 三个月后回头看，楼变高了、亮的窗变多了，这个是小人给不了的。而天空让你不看列表就知道「今天用不用我」——这是这个看板最核心的一句话。

03光之河 配菜 · 原创

活动流今天是另一页上的一列文字。这里把它变成看板页底下一条河：每件事是一颗漂过去的光点——认领是蓝的、完工是绿的、待拍板是琥珀的、阻塞是红的—— 带着图标和几个字慢慢从右往左漂，鼠标按住它就停下来给你看。忙的时候河里挤满了，闲的时候只有水面上一层你选的配色在晃。

04光轨 备选 · 原创

看板的泳道是静止的，卡「换了状态」这件事今天是刷新一下就换了位置，眼睛跟不上。光轨在泳道头之间拉一条霓虹轨道，轨道上常年有细碎的光在往「收官」方向流（工作的方向）； 一张卡换泳道时，一颗光珠沿轨道从旧泳道跑到新泳道，然后那张卡在新泳道里落下来。看得见「事情在往前走」。

为什么是备选。它跟城与天讲的是两件事（一个讲流动、一个讲积累），可以同时要；但如果只挑一样，城与天更耐看。

06施工现场 兜底 · 你说的那种

像素办公室那个思路的看板版：施工中的卡各占一张桌子，屏幕上跑流光；有 Codex 在跑的桌子前坐一枚机器人在打字；待拍板的桌子上方举着一只手；卡住的桌子亮红灯； 完工那张桌子撒彩带、灯变绿、桌子收走。没画小人走路——那是抄人家的地方，也是最费工、最容易做得廉价的地方。

我的看法。它能用，但它跟城与天讲的是同一件事（谁在干活）而信息更少：桌子只有「有 / 没有」，楼里的窗还带着「攒了多少」。 真要的话我会做，但不建议两个都要。

07推荐组合，与要你拍的

组合包含说明
A · 推荐城与天 + 光之河 + 追光 + 盖章 + 飞卡顶上一座城、底下一条河，卡片有手感。约三到四天。
B · 全要A + 光轨再加泳道之间的轨道。多一天。
C · 只要主菜城与天一天半到两天，最快看到东西。
D · 兜底施工现场（+ 小料）你说的那种。两天。
要你拍两下。①选哪个组合（或者划掉某样 / 加回某样）。②城与天的楼要不要全部项目都摆出来——我画的是全摆（点楼切项目），另一种是只摆当前项目一栋大楼，更简洁但少了「一座城」的感觉。
没画但能顺手带的。「减少动效」打开时：极光停、云不飘、雨停、窗不闪，只剩静态颜色；楼和河都还在，信息一点不少。
