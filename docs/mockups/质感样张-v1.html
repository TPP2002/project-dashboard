质感样张 v1 · 块状 vs 合格

负责人的话："像 Python 初学者画圆画矩形画出来的块状动画。"这页把同一样东西用两种画法并排：左边是块状（几何原型当物体、一物一色、硬边、不照亮周围、刚体运动），右边是这个项目要的（有机轮廓、冷暖分离、软边层叠、辉光与受光、有生命曲线的运动）。标准全文在 docs/plans/AUD-FUN-WORKFLOOR/质感标准.md，以后每张画面工单都按它验收。

四组对照：火焰 / 烟 · 排气冷气 / 灯塔光束 · 全部 SVG 矢量 + 滤镜，无外部依赖 · 2026-09-08

块状为什么块状圆当烟、三角当火、矩形当雾；一物一色只变深浅；全带黑边；光源不照亮周围；东西平移或直接出现。
合格的四件事有机轮廓 + 噪声扰动；冷暖分离（阴影偏蓝、亮部偏暖、火光染橙、月光染蓝）；软边层叠不描线；每个光源有辉光并照亮它该照亮的面。
以后每张画面稿按这八条验收（docs/plans/AUD-FUN-WORKFLOOR/质感标准.md §3）
  1. 放大 200%，找不到裸露的几何原型当物体。
  2. 光、气、火、水没有黑边硬边。
  3. 每个光源周围有辉光，且照亮了它该照亮的东西。
  4. 阴影偏冷、亮部偏暖，火光和月光互相染色。
  5. 任何运动有缓动或惯性；粒子有生长-衰减曲线。
  6. 前景 / 中景 / 背景分得出来。
  7. 同类重复元素有变化。
  8. 缩到 50% 仍分得清材质；放到 200% 每块面都有东西。
