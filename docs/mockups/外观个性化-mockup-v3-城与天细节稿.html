01整体：看板页上的一整天

顶上是城，泳道上有光轨，底下是河。下面这排按钮把整条链路串起来看：「完工一张」会让施工中那张卡抬起来飞进楼里、窗户亮起，接着河里跳出一条锦鲤； 「来一条待拍板」云会飘来、天上打一道闪、河里游来一条琥珀色的鱼；「卡住一张」开始下雨、游来一条红河豚。

销卡是这样的。看板页本来就不显示收官泳道（默认收起）。所以完工那一下不再是「落进某一列」，而是卡抬起来、缩小、拖着一道光飞进它所属的那栋楼，对应的窗白光一闪然后亮成暖黄——卡没了，楼高了一格。泳道里的空位由下面的卡补上来。

02城，放大看

同一座城的放大版。楼是按数据长出来的：窗数 = 卡数，超过九层自动退台成两截（下宽上窄），所以每栋楼的轮廓都不一样。 点楼切项目——当前项目描一圈蓝虚线，别的楼略暗。这里的按钮只影响这一块。

楼身正面有明暗渐变，右侧一条暗面、顶上一条亮面，看得出是个立体的块；超过九层退台成两截；每扇窗有窗框和窗台线，完工的窗有两种暖度随机交错，不是一片死黄。
屋顶女儿墙、左边水箱（带支脚）、右边空调外机（带格栅）、天线（顶上一颗航空灯：平时暗红慢闪，有待拍板变琥珀、有阻塞变红快闪）、屋顶招牌写着项目名（用项目色，夜里发光）。
门厅底楼正中一扇亮着的门，上面一片雨棚。
塔吊楼上有施工中的卡才立：格构塔身、起重臂、平衡臂和配重块、司机室（亮着灯）、小车沿臂来回走、吊索随之收放、吊着一根钢梁轻轻晃、塔顶警示灯。第 03 节有放大图。
地面人行道、马路（虚线车道线）、来往的车（夜里只剩车头灯和尾灯的光）、路灯（夜里有光锥）、行道树。
天白天：太阳的柔光、飞鸟、白云带阴影。夜里：星星眨眼、月亮和月晕、每十几秒一颗流星、极光丝带（三条，形状慢慢起伏，用你选的配色）。
天气待拍板 = 云来（越多越厚）+ 新来一条时一道枝状闪电劈向那栋楼；阻塞 = 下雨，地上有水花，湿地面映出楼的倒影；全清 = 极光。
远景楼后面一排更远、更暗的剪影楼，零星几点小灯，把画面拉出纵深。
100%尖塔亮起、塔尖一颗白星，楼顶放三轮烟花（只放一次）。

03塔吊，放大看

放大八倍的那台塔吊，各部件标了名字。它是活的：小车沿起重臂来回走，吊索跟着收放，吊着的钢梁轻轻晃，塔顶警示灯慢闪。

为什么能画这么细而不卡。全是矢量线条，一台塔吊二十来根线；一座城三四栋楼、一两百扇窗、一台塔吊，浏览器画起来跟一段文字差不多重。动的部分（小车、吊索、闪烁）都是 CSS 动画，不占脚本。

04光之河，重画

上一稿的河只是一条会闪的色带，不像水。这一稿：三层波浪各自以不同速度往左流、最上面一条白色浪花线；水面映着楼的灯光（竖向的彩色倒影，用你选的配色，慢慢晃）；偶尔冒气泡。 河里游的不再是标签，是鱼：认领来一条蓝鱼，待拍板来一条琥珀色的，阻塞来一条红河豚（带刺），完工来一条锦鲤，并且会跳出水面。鼠标放上去鱼停下来、显示它是哪张卡；点它开卡。

为什么是鱼而不是别的。你提了鱼，我比较过河灯和纸船：河灯只有「亮 / 不亮」一种表情，纸船分不出四种事；鱼有颜色、有体型、还能跳，四种事一眼分开，完工那一跳正好接住楼那边的窗户亮起。 要是想要更安静的版本，鱼可以换成河灯只在完工时放一盏——一行配置的事。

05光轨与销卡

泳道头之间那条霓虹轨道保留：常年有细碎的光往前流；「认领」时一颗光珠从待开工跑到施工中，卡在那儿落下。 「完工」不再往右跑——卡直接抬起，拖着光飞进顶上的楼。第 01 节的两个按钮就是这两个动作，这里不重复画。

06你问的额度：日常一分不多花

这些东西不花 AI 额度。它们全是浏览器里画的画，吃的数据就是看板已经有的那份（哪张卡什么状态、什么时候完工）， 没有任何一步要问模型、不多打一个接口、服务端一行不用改。会话在干活时和现在完全一样，多的只是你屏幕上多了一座城。
