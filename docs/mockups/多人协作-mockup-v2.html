要你定:成员和只读访客能看到多少

这是一张「谁推进了多少」的表,摆出来对团队有激励,也可能让人有被比较的压力。负责人自己永远看全部。下面三档只管成员和访客。

甲 · 成员看全员,访客只看总数 推荐

负责人全部
成员全部(五个总数 + 按人表 + 趋势 + 动态)
只读访客只看五个总数和按周趋势(不分人)

好处:团队里谁在推进一目了然,协作人的功劳看得见,大家自己会补位。访客多半是外部看进度的人,只给总数,不暴露谁干得多谁干得少。

代价:成员之间能互相看到数字,个别人可能觉得被比较。

乙 · 成员只看自己,访客只看总数

负责人全部
成员五个总数 + 自己那一行 + 自己的趋势
只读访客只看五个总数和按周趋势(不分人)

好处:没有互相比较的压力,每个人只对照自己的节奏。

代价:成员看不到别人在推进什么,「谁在帮谁」的协作信息只有你看得到;要多做一套「只看自己」的界面。

丙 · 全员都看全部

负责人全部
成员全部
只读访客全部

好处:最简单,一套界面,一份接口。

代价:外部访客也能看到每个人的数字;邀请外部人员前得先想清楚。

无论选哪档:数字都是从卡片和活动记录现算的,不另存;访客自己也会出现在表里(数字是 0),如果你觉得没必要,前端可以只列成员。限制在服务端做,不是前端藏起来。
