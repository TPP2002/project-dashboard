看板 · 城与天画风方向对比 v4

上一稿的画风被否——你说它像文艺动画片。这一稿不加功能，只回答一个问题：选哪种画风。 同一个场景（两栋楼、一台塔吊、河边的倒影、两条鱼、夜空）用三种截然不同的画法各画一遍，都是夜景，白天版等方向定了再画。 三个方向的楼都是按同一份数据长出来的：窗 = 卡，楼随卡的积累长高、随完工亮灯。

先把你四条意见对上号。①河里的倒影对不上楼的灯：因为上一稿河在页面最底下、楼在最顶上，中间隔着泳道，倒影只能是「意思一下」。 这稿把河直接放在城脚下（城在河边），三个方向的倒影都是楼本身翻过来的镜像，哪扇窗亮倒影里就哪里亮，鱼在倒影里游。 ②楼会不会随项目推进变化：会，第 04 节有个时间轴拖着看。③完工 / 拍板时整片天黄闪：那是个 bug（闪电的开关打上没关，之后每次重画都重播），已修；三个新方向里闪电本身也重画了。 ④更多互动：第 06 节列了清单。

01方向 A · 像素城 canvas 逐像素

老式主机游戏那种像素画：每一个点都是画上去的，窗框一像素、塔吊格构一像素、水里的倒影按行错位抖动。放大不糊（整数倍放大），细节靠一笔一笔堆。 和你喜欢的那个像素办公室是同一门手艺，但画的是一座城不是小人。

02方向 B · 霓虹线框城 SVG 发光线稿

只画轮廓线、不填面，所有线都发光，楼的棱上有一道 RGB 光在跑；窗是一格格霓虹管；地面是往远处延伸的发光网格；水面是带涟漪的镜像。 这是三个里最「RGB」的一个，赛博味最重。

03方向 C · 等距建模城 SVG 等距投影 · 推荐

斜 30° 俯视的 2.5D，每栋楼是真的立体块（顶面、左面、右面三种明暗），两个面上都有窗；塔吊是立体的；地面是铺砖的广场和马路；河面是等距的水面，倒影是楼的镜像。 夜里楼的棱上跑 RGB 灯带、招牌发光。最像「建模」的一个，细节上限也最高，白天夜里都成立。

04楼会不会长：拖着看

会。一栋楼的形状完全由数据决定：卡越多楼越高（新建卡就是加一扇黑窗，攒满一层就多一层），完工越多亮灯越多（从下往上亮）， 超过一定高度自动退台成两截。里程碑上加东西：第一张卡开工立塔吊，完工过四分之一屋顶招牌点亮，过一半架天线，全部完工亮尖塔放烟花。 下面用方向 C 的楼演示这个项目从第 1 天到今天：

真实数据里还会有一层「时间」。楼不是按今天的快照画的：看板的活动流里有每张卡什么时候建、什么时候完工，所以这条时间轴在产品里是真的能拖的——拖回三周前，就看到三周前的城。

05鱼的三种画法

上一稿的鱼你不喜欢。三个方向各有自己的鱼——像素鱼是 14×7 个点画的锦鲤；霓虹鱼是发光线条带光尾；等距鱼是一条小体素锦鲤。都比上一稿细。

06互动与动画清单（三个方向通用）

窗就是卡鼠标放到一扇窗上，弹出那张卡的编号和标题；点它打开卡。楼是活的看板，不是装饰。
点楼进镜头点某栋楼，镜头推进到那栋楼（放大到窗户能看清），再点回退。切项目就是这个动作。
时间轴第 04 节那条，拖回任何一天看当时的城；松手回到今天。
完工 = 销卡飞进楼卡从泳道抬起、拖光飞进楼、窗亮、河里锦鲤跳。保留。
认领 = 塔吊起吊认领一张卡时，塔吊把一块「砖」吊上楼顶（新窗从黑变成流光）。比光珠沿轨道跑更贴这座城。
待拍板 = 招牌闪 + 举旗楼顶招牌切成琥珀色闪烁，屋顶升一面小旗；拍掉就落旗。不再用整片天变黄。
阻塞 = 停工塔吊停摆、警示灯转红、那层窗红闪；解除后塔吊重新动起来。
日夜跟真实时间天色按你电脑的时钟走：早上泛白、傍晚橙红、夜里深蓝；也可以钉死夜景。
天气晴 = 极光（RGB）；有待拍板 = 云；有阻塞 = 雨；里程碑 = 烟花。闪电改成劈向楼顶避雷针的一道细亮线，不再染天。
鱼点鱼它会加速蹿一下；锦鲤跃出水面带水花；鼠标放上去停下显示是哪张卡。
车流 / 路灯 / 塔吊常驻小动画，让城一直「活着」；系统减少动效时全部静止只留颜色。
换配色右上角那个按钮：RGB 流光、极光、灯带、鱼尾光全跟着你的灯条配色变。

07三个方向对照，与我的推荐

A · 像素B · 霓虹线框C · 等距建模
气质复古游戏、手工感赛博、极客、夜店沙盘模型、建筑效果图
RGB 流光能做（逐帧换色），但像素粗，光不柔本身就是光，最强棱上灯带 + 亮窗 + 倒影，强且不刺眼
细节上限看像素功夫；越细越费手线稿天生简洁，细节靠线的密度，多了会糊成一团最高：每个面都能加东西，放大也成立
白天版成立不成立（白底上没光）——白天只能当「暗色卡片」成立（白天就是正常的效果图光照）
和看板界面的搭配反差大，像嵌了个小游戏只配深色主题和现在的界面同一种克制，深浅都搭
性能canvas 每秒重画 12 次，稳定但一直在算发光滤镜多了会吃 GPU矢量 + CSS 动画，最省
工程量最大（每个东西都要画像素图）最小中
我推荐 C。理由：你要的是「精致建模、更多细节」，C 是唯一一个能一直往里加细节还不散架的；RGB 它不缺（夜里棱上灯带、亮窗、倒影、极光全在）； 白天版成立，不用为浅色主题另想办法。B 最炫但白天没法看、久了累；A 有趣但风格太强，跟看板其他页面像两个产品。 要是你看完更想要 B 的那股劲，可以 C 打底、夜里把灯带和辉光调到 B 的强度——两者本来就共用一套几何。
要你拍的：选方向（A / B / C，或 C+B 的混法）。定了我再出那个方向的全细节稿（白天 + 夜里 + 天气 + 塔吊放大 + 鱼 + 时间轴 + 全部互动），然后开工。
