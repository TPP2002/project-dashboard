看板 · 图标体系 mockup v1 AUD-UI-ICONSET-NO-EMOJI · 待过目

目的只有一个:把界面里的 emoji 全部换成一套统一的线条图标。不改配色、不改布局、不改字号间距——所有色值与令牌照抄 base.css,你现在满意的样子保持不动。每一组都左浅右深并排给你看。

一套图标,一个来源24×24 网格、1.75 描边、圆头圆角;内联 SVG 精灵,零依赖、零网络请求。约 45 个够用。
图标只做辅助,不做主角颜色永远继承文字色(currentColor),不自己带色;需要语义色时由所在徽章/文字给。
状态 = 形状 + 语义色十个状态各一个形状,配现有五档语义色(n / info / warn / ok / bad);色弱也能靠形状分辨。
尺寸只有四档14 徽章内 · 16 行内与卡片 · 20 页头 · 32 空态。不出现别的尺寸。
终端不动CLI 输出、INDEX 渲染里的 emoji 保留——终端里它是最紧凑的表达;只改网页。

01图标全集(45 个)

左列浅色、右列深色,同一份 SVG。名字是将来 <Icon name="…"> 的 key,下面一行小字是它替换的对象。

02状态体系:十个状态,形状 + 语义色

这是全站用得最多的地方(泳道头、卡片、抽屉、总览、波次、风险、验收)。现在「已拍板」和「已完工」共用一个 ✅,靠位置猜;方案里已拍板是空心勾、已完工是实心勾,施工中用锤子,暂缓用暂停,一眼分清。第 11 行「已作废」是报告建议新增的状态,先把形状占上。

03页头:去掉 🚀 这类符号,图标退到文字色的次级灰

页头图标用 20px、颜色是 text-2(比标题淡一档),不抢标题。也给出「完全不要图标」的版本(见每组最后一行),你可以二选一。

04任务卡与抽屉里的小标签

卡片上的 ❓ 待拍板角标、🌿 分支、🤖 档位;抽屉里的 🚧 阻塞、🅿️ 暂缓遗留、🔄 复工依据、📁 文件域、⛔ 禁区、📄 文档,全部换成 14px 图标,放在原来的位置、用原来的徽章底色。

05侧栏导航:现在用的是字符符号(⌂ ▦ ◎ …),要不要一并统一?

侧栏上一轮重构已经不用 emoji,用的是 Unicode 几何符号,但各字体下粗细不一、在 Windows 上偶有缺字。建议一并换成同一套图标,粗细才会一致。左边是现状,右边是方案(两栏都用浅色,好直接比)。

06空态、折叠开关、活动类型、连击

空态的大 emoji(🎉 ✨ 📭 🈳)换成 32px 淡色图标;「显示已完工」开关的 🗂️/✅ 换成归档/勾;活动流每种类型一个小图标;每日成果的 🔥 换成火焰线条图标(仍用警示色)。

07实施说明(给施工方看,你可以略过)

方案通过后,施工只做三件事:加一个 Icon 组件、加一张 emoji→图标映射表、把 web/src 里出现的 emoji 逐个替换。CLI 与 core 不动。

// web/src/components/Icon.vue —— 唯一的图标出口
<Icon name="hammer" :size="16" />          // 行内
<Icon name="help" :size="14" />            // 徽章内
<Icon :name="statusIcon(task.status)" />   // 状态:api/schema.ts 里 STATUS_ICON 映射
<Icon name="inbox" :size="32" class="empty-ic" />

// 规则
· 只有 14 / 16 / 20 / 32 四档;stroke 1.75(32 档 1.5)
· 颜色永远 currentColor,不传 color prop
· 装饰性图标 aria-hidden;单独承载语义时 role="img" + aria-label
· 全部 path 内联在一个 <svg><symbol> 精灵里,构建期打进主包,不引 icon 库
· core/boardSchema.cjs 的 STATUS_EMOJI 保留给 CLI;前端不再 import emojiFor
