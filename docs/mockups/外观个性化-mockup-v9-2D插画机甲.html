明暗每块板：基色渐变 + 上缘高光棱线 + 下缘硬阴影面；主色蓝 / 浅蓝二色 + 深灰骨架 + 金饰 + 红灯；全身统一左上光源；外轮廓 2.2px、内部面板线 1.1px，放大不变粗（矢量描边不缩放）。
未装 / 焊接中未装 = 青色全息投影（平台两枚投影器打上去的，不是虚线）；焊接中 = 半透明实体 + 焊缝沿轮廓亮起（长度 = 进度）+ 扫描线上下走 + 焊接无人机在旁边打火花；待拍板 = 琥珀色闪 + 橙色检验无人机飞来扫描；阻塞 = 红色闪 + 龙门塔警灯 + 全场红光；完工 = 部件白闪一下扣上；项目 100% = 通电悬浮。
手臂定位左右手臂的横向间距固定在外层支架上，呼吸起伏只作用于部件本身；扫描线按移位后的部件轮廓定位，焊到前臂时仍对准前臂。
工业零件架带竖向拉丝的洞洞板、开孔槽钢、角撑、三层厚钢板和条码货位条；待装件落在板面上，带接触阴影、高光棱线和吊牌。架顶挂扳手、线缆与焊枪，底座有警示斜纹和在线灯。
装配控制台金属外壳带螺钉、铭牌和实体按钮；玻璃叠扫描线、微光与斜向反射。剪影与二十九格进度条同步显示部件状态，下方保留最近三条事件，时钟逐秒更新，通电后波形变绿、振幅增大。
机库材质墙板斜向拉丝、接缝亮暗边与固定污渍；地面花纹钢板、平台周围磨痕、台面同心刻线和警示外圈；管线高光与双箍、栏杆底座、灯罩内壁和双层光锥共同表现厚度。全场只叠一层静态细颗粒。
减少动效跟随系统设置停止呼吸、摆头、悬浮、闪烁、旋翼、灯带、波形和事件过渡；扫描线静止，无人机直接落位，焊接不生成火花。按钮、装配进度和状态颜色仍保留。
