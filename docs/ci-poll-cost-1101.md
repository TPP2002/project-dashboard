# 检查作业轮询降耗

- 全仓共用并发限额，默认同时最多 4 个请求，可用环境变量调整为 1~16。
- 项目远端缓存 10 分钟，板文件的修改时间和大小未变时复用内容。闲置仓每 4 拍查询一次，无页面连接超过 2 分钟后暂停，重连时立即恢复。
- 估算：9 个仓各有 6 个活动 run 且无额外分页、标题查询或历史采样时，改前每拍约 72 次请求，改后活动状态下仍约 72 次，但并发峰值从最多 36 降至 4。空闲仓原为每拍 2 次，改后每 4 拍 2 次；历史采样按原窗口另计。实际请求数随活动和分页变化。

| 用例 | 改前场景 | 改后场景 | 验证目的 |
| --- | --- | --- | --- |
| 一个仓库尚未返回时，下一拍仍能刷新其它仓库且不重复占用慢仓库 | 两仓均无活动 run | ① 两仓各有一个活动 run | 原断言不变，仍检查慢仓不阻碍另一仓刷新 |
| 最后一条历史失败仍复用此前完整明细，恢复只补缺项；不缓存半页或运行中结果 | 仓库无活动 run | ① 增加一个活动 run | 原断言不变，仍检查历史明细复用及失败恢复 |
| 历史缓存区分仓库/run/attempt，移出100条窗口及删除仓库都会回收 | 两仓均无活动 run | ① 各仓增加一个活动 run | 原断言不变，仍检查历史缓存隔离和回收 |
