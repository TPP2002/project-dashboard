# 远程主机监控

看板可以显示远程主机的处理器、内存、磁盘、任务和性能曲线。先在远程主机安装采集程序：

```text
node scripts/remote-host-install.cjs --target my-server
```

安装脚本由采集程序提供。完整传输协议见 `remote-agent/README.md`。

配置文件默认为看板数据目录里的 `remote-hosts.json`，也可通过环境变量 `DASHBOARD_REMOTE_HOSTS_FILE` 指定文件。示例：

```json
{
  "hosts": [
    { "name": "my-server", "label": "远程主机", "targets": ["my-server"] }
  ]
}
```

`targets` 可以填写 1~4 个 SSH 别名或登录目标。`agentPath` 和 `python` 可选，缺省分别为 `/opt/hostmon/hostmon.py` 和 `python3`。配置变更后无需重启看板，30 秒内自动重读；配置有误时接口会返回原因且不会启动连接。

连接断开后，页面可以继续显示上次收到的数据，并将其标记为过期，同时显示原因。服务会自动尝试重连。

三个接口均使用 GET：

- `/api/sched/remote-hosts`：返回 `ok`、`configError` 和 `hosts`。主机字段为 `name`、`label`、`status`、`target`、`ageMs`、`stale`、`error`、`notice`、`agentVersion`、`daemon`、`host`、`latest`、`capacity`、`disk`、`spark`、`tasks`、`taskCount`、`totals` 和 `procsAt`。`disk` 为根挂载点的容量和用量，没有根挂载点时取容量最大的挂载点，无数据时为 null。
- `/api/sched/remote-hosts/<name>/perf?range=60s`：返回 `name`、`range`、`resolution`、`points`、`host`、`latest`、`status` 和 `stale`。范围可为 `60s`、`10m` 或 `24h`，省略时为 `60s`。
- `/api/sched/remote-hosts/<name>/processes`：返回采集时间 `at`、总数 `totals`、任务 `tasks`、进程 `processes`、省略数量 `omitted` 和完整挂载点数组 `fs`。
