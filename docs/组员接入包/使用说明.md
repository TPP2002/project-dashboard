# 组员接入云端看板

云端看板：https://124.222.101.139

接好后，你的 AI（Claude Code、Codex、Cursor 等）能替你查卡、建卡、领卡、报进度、留言、完工，权限和你在网页上一样。一共两步。

## 第一步：登录（你本人做，约 1 分钟）

**Windows**：双击 `一键登录-Windows.cmd`，按提示输入看板用户名和密码，再选默认项目。

**Mac / Linux**：打开终端，粘贴这一行回车，按提示输入用户名和密码：

```bash
mkdir -p ~/tools && curl -fsSo ~/tools/board-member.cjs https://124.222.101.139/board-member.cjs && printf "看板用户名：" && read U && node ~/tools/board-member.cjs login --server https://124.222.101.139 --username "$U"
```

有多个项目的，再运行 `node ~/tools/board-member.cjs projects` 看编号，`node ~/tools/board-member.cjs use 项目编号` 设默认项目。

电脑上要先装好 Node 18 或更新版本（https://nodejs.org 下载 LTS 版）。密码不会存到电脑上，存的是这台电脑专用的登录凭据，90 天有效。

## 第二步：交给 AI（全自动）

在要接看板的项目里打开你的 AI，把 `发给你的AI.txt` 的内容整段发给它。它会自己检查登录、读使用说明、把看板规矩写进项目的 `CLAUDE.md` 和 `AGENTS.md`，最后把你手上的卡列出来确认能用。

之后在这个项目里干活，AI 会自己领卡、报进度、完工。换别的项目，在那个项目里再发一次第二步就行。

## 遇到问题

| 情况 | 怎么办 |
|---|---|
| AI 说要重新登录 | 重做第一步 |
| 换了电脑 | 新电脑上重做两步 |
| 电脑丢了或不再用 | 在旧电脑上运行 `node 命令行路径 logout`；旧电脑用不了的话，请负责人在网页上撤销这台设备 |
| 看板升级了 | 一般不用管；负责人通知要更新时，重做第一步 |
| 连不上 | 先用浏览器打开看板网址，打不开就是网络或服务器问题，找负责人 |
