## 改了什么、为什么

- `core/projectIndex.cjs` 异步检查登记文件的修改时间与大小。未变时复用解析结果；变了才重新解析，整表替换。单项目失败记空值，登记读取失败保留旧表，相同连续错误不重复刷日志。刷新结果告知调用方本次是否重建，供探活缓存触发刷新。
- `core/boardPoller.cjs` 并发异步读取板文件状态，一次只跑一拍，重入时计跳过。慢拍逐次翻倍到 30000 毫秒，耗时恢复后回到 1500 毫秒。使用不阻止退出的超时链。
- `core/healthSource.cjs` 从内存返回项目清单、发行提交号和其他探活字段。后台异步读取，失败保留旧值。定期刷新与登记变化触发的刷新共用一次在途请求；在途期间再触发只记脏，完成后补跑，不并发两份。
- `server/server.cjs` 在监听前刷新一次项目索引。板扫描交给新轮询器；协作清理与调度读取保留在原周期，CI 轮询代码未改。首次见板仍记基线并通知，板修改仍更新基线、广播相同事件与载荷并通知。
- 探活从内存取全部读盘字段，并在路由读取模块设置之前处理。挂钩探测保留代码仓、项目归属锚和工作树指针口径，读取改为异步；设置、产物状态和发行戳也在后台异步读。

磁盘拥堵时，探活不会再等待这些文件操作；轮询也不会堆叠新拍。登记变化时的既有项目路径解析仍按原模块执行，属于批准保留的同步路径。

## 刷新时效

| 字段或触发条件 | 刷新时效 |
| --- | --- |
| 项目清单 | 正常下一拍，默认不超过 1.5 秒；退避期间为当前退避间隔，磁盘耗时另计 |
| 发行戳、挂钩安装状态、设置、产物状态 | 默认每 30 秒异步刷新；读取失败保留前值 |
| 登记文件变化触发的即时刷新 | 下一拍发现变化后立即异步刷新，不等待 30 秒节拍；在途刷新合并为脏标记，完成后补跑 |
| 模块开关与 webhook 开关 | 接口保存后立即更新内存并生效；外部改文件后下一拍（默认 1.5 秒）起异步刷新 |

磁盘阻塞可能推迟后台结果更新，探活请求仍只返回内存中的结果。

## CI 红的 4 条与处理

PR #154 的全量检查发现原 A2 清单外有四条失败。原因是接口保存设置后，探活仍返回 30 秒缓存；服务重启时也未等待首次后台读取就监听。仅让外部写盘用例等待，不能解决接口保存后的即时可见要求。

| 文件与用例 | 处理 | 原断言 |
| --- | --- | --- |
| `test/modules.test.cjs`：默认模块全关，菜单保存后立即放行；关闭后立即拦截 | 接口保存成功后立即更新探活内存；末尾直接写文件的部分新增最多 5 秒、间隔 100 毫秒的等待 | 全部保留，仍检查完整模块清单 |
| `test/modules.test.cjs`：试听台模块保存后立即生效，关闭后读写都被拦截 | 通过接口保存后的内存更新恢复即时可见 | 用例未改 |
| `test/collaborationHealth.test.cjs`：owner receives existing complete health and saved cost/cpu switches on the next GET | 所有成功保存设置的请求都在响应前更新同一份内存缓存，保持环境变量覆盖口径 | 用例未改 |
| `test/webhook.test.cjs`：真实事件推送、初始基线、服务端事件选择与同源设置校验 | 保存推送开关后立即更新内存；启动时等待首次探活读取完成后再监听，保证重启后首次请求读到文件值 | 用例未改 |

`healthSource.patch(partial)` 只合并内存字段，不读盘、不触发后台刷新。`handleSettings` 使用 `writeSettings` 成功返回的设置值更新模块开关和推送开关，再发送成功响应。

`pollServices` 每拍异步检查设置文件的修改时间和大小；未完成的检查不会重复发起，指纹变化才触发探活缓存异步刷新。读取状态失败统一视为指纹为空，删除、恢复同样能触发变化。该检查不等待后台刷新，也没有新增同步文件操作。

新增假文件系统测试验证：内存更新立即可见且不增加读盘次数，后续读取已保存的新内容不会恢复旧值；设置文件检查不重叠，时间或大小变化、删除及恢复均能触发刷新，相同指纹不重复刷新。

派单方要求扩充后的 A2 包含新增的三个文件。但本轮第 11 次自测回执打印的实际命令仍只含原六个文件，未列 `test/modules.test.cjs`、`test/collaborationHealth.test.cjs`、`test/webhook.test.cjs`。此外，检查运行期间更新施工记录导致内容指纹变化，该次整组被作废。虽然副机返回执行通过，也不计为有效通过证据，不能证明四条 CI 回归已经复核通过。
