# 试听台

试听台用于在项目的游戏画面上比较声音、盲听、留批注、看授权和回答看板拍板题。声音与游戏画面由项目方准备；看板不上传、生成、剪辑声音，也不改游戏画面。

## 开启与入口

1. 在看板「菜单设置 → 扩展模块」打开「试听台」，或在 `DASHBOARD_HOME/settings.json` 的 `modules` 中设置 `"audition": true`。只有布尔 `true` 开启，缺失及脏值均关闭。
2. 环境变量 `DASHBOARD_MODULES` 存在时优先于设置文件。名单中加入 `audition` 可开启，`all` 全开，空字符串全关。
3. 在项目的 `docsRoot` 下放置 `docs/design/audio/试听台/audition.json`。`docsRoot` 由既有 `resolveProject` 解析，未配置时回落 `mainRepo`。
4. 侧栏仅在模块开启且当前项目索引读取成功时显示入口；项目之间分别缓存，切项目重新查询。添加清单后可切换项目重新读取，页面内也有「刷新」。

路由为 `/audition`，使用看板现有的哈希路由方式。模块未开沿用其他扩展页的路由保护；已开启但没有清单时显示「本项目还没有试听清单」。不需要为其他项目建立空清单。

## 仓库索引

路径相对于 `docsRoot`，格式为：

```json
{
  "schemaVersion": 1,
  "batches": [
    {
      "key": "dir-r1",
      "title": "声音方向试听 · 第 1 轮",
      "path": "docs/design/audio/试听台/方向试听-第1轮/batch.json",
      "task": "AUDIO-DESIGN",
      "addedAt": "2026-09-12",
      "status": "待试听"
    }
  ]
}
```

`key` 必须匹配 `/^[A-Za-z0-9_-]{1,40}$/`，索引中不能重复。批次按索引顺序展示。批注数、好/不好数量和审阅状态从本机账本派生，不回写索引。

示例中的标题、作者和来源链接须替换为真实信息，每个需要试听的组与场景组合分别填写片段。

- `screens[].path` 相对于 `docsRoot`；`width`、`height` 缺省分别为 1920、1080。画面以此尺寸布局，再整体缩放，不更改画面内容。
- `scene.screen` 缺省使用 `defaultScreen`。`level` 的 1～5 显示为最轻、轻、中、重、最重。
- `groupNoun` 是列的叫法，如「方向」「候选」。组和场景的 `id` 分别唯一；每个 `(group, scene)` 只能有一个片段。
- `clips[].files` 相对于该批次文件所在目录，1～4 个，只支持 `.mp3`、`.ogg`、`.wav`，每个文件必须存在。多文件按顺序轮换，避免紧邻重复。
- 每个片段至少一条 `sources`，`license`、`url` 不得为空；授权含 `CC BY`、`CC-BY` 或 `Attribution` 时必须提供 `attribution`。界面标出「需署名」，但不替代项目方核验真实授权。
- `decisions` 精确引用当前项目看板的卡与决策。`optionGroups` 的键是**拍板选项全文**，值是组编号。有映射的选项可「听这一组」；「都不满意」等未映射选项仍可正常拍板。
- 批次中的局部错误逐条进入 `problems`，正常条目仍可浏览；缺片段时不播放并提示。非法请求、越界、无法解析的索引/批次等返回中文错误。

## 游戏画面消息约定

画面必须是同源页面，只使用可信的项目画面文件。页面内保留原有本地交互，把需要响声音的事件发给父窗口：

```js
window.parent.postMessage({
  source: 'audition-screen', type: 'ready', scenes: ['buy_fill']
}, location.origin);

// 在原有的成交按钮处理完成后发送，不由试听台代下单。
window.parent.postMessage({
  source: 'audition-screen', type: 'trigger', scene: 'buy_fill'
}, location.origin);

// 画面会收到下面这条消息，无需回应。
// { source: 'audition-desk', type: 'hello' }
```

试听台同时检查 `event.source === iframe.contentWindow` 和 `event.origin === location.origin`；同一场景 80 毫秒内重复触发只处理一次。只有批次中声明的场景会播放；播放的是当前组，盲听时使用当前盲组。

游戏画面通过 `/api/audition/file?project=项目编号&path=相对路径` 读取。网页允许内联脚本和内联样式；`connect-src 'none'` 禁止页面自身发出接口连接，`frame-ancestors 'self'` 限制嵌入来源，并禁止表单外发、对象和子画面。图片、媒体、字体可内联为 `data:` / `blob:`。图片需要独立文件时使用上述文件接口的完整地址；普通相对资源地址不会自动转换为清单路径。字体请内联，文件接口不开放字体扩展名。外部脚本、样式或远程资源不在本约定内。

## 试听方式与本地偏好

- 第一个用户手势才创建或恢复 Web Audio；音量默认 70，范围 0～100。解码结果按素材地址缓存。
- 盲听按显示在页面上的整数种子洗牌，算法为 mulberry32；方向使用 X/Y/Z…，候选使用 1/2/3…。「揭晓」前隐藏真实组名、说明、来源与可能透露名称的拍板选项。
- 同场景对比按当前显示组顺序播放，片段之间隔 0.9 秒；整组按场景清单顺序播放，隔 0.8 秒。
- 疲劳测试对选定场景连播 20 次，间隔 450～1100 毫秒，速率在 ±2% 内变化，均由当前种子决定。多素材仍轮换。
- 全部模式均可随时停止。切项目、切批次及离开页面会停止旧播放，迟到的网络响应不会把声音或批注投到新项目。
- `localStorage` 键 `board-audition-preferences` 保存 `{volume, seed, blind, shelfCollapsed, railCollapsed}`。读回逐字段校验，种子范围为 -2147483648～2147483647；坏字段分别回落 70、1、false、false、false。两栏折叠状态独立校验，旧设置缺少任一字段时该栏默认展开，其他有效设置保留。揭晓状态不持久化。

## 场景批注、整组原因与布局

- 每个场景行的「批注」显示当前组在该场景的批注数。展开后可以新增、编辑、取消编辑、保存和删除；修改过的显示「已修改 · 时间」。点击「好」或「不好」会自动展开并聚焦新批注框，原因可以不填，也可以直接收起。
- 行内与「批注」分页共用同一个账本和串行保存队列，保存后两边立即更新。分页继续提供全部批注总览、新增、删除、导出和标为已审阅；未揭晓时两处组名均沿用盲组名。
- 整组倾向下方可以填写原因。选择倾向时一并保存框内原因，也可单独点「保存原因」。已保存的原因显示在框下并可再次修改；清空后保存会删除原因，再点已选中的倾向会同时清除倾向和原因。
- 侧栏固定批次标题、分页按钮和播放状态条，其余内容共用一个滚动区。批次简介默认只显示一行，点「展开」可看全文；批次说明放在「试听」最底部随内容滚动。状态行覆盖通用进度条的固定高度，避免文字被裁掉。
- 批次架和试听侧栏标题处均可「收起」，收起后保留当前批次的简写以及带无障碍名称的展开按钮，支持键盘操作。桌面左列从 190 像素缩为 64 像素，右列从 390 像素缩为 64 像素；腾出的空间交给舞台，原有 `ResizeObserver` 按容器重新计算 `--screen-scale`。侧栏收起时保留分页和草稿，播放中的状态与停止按钮仍可见。
- 工作区通过 `auto minmax(0, 1fr)` 分配标题和剩余页面高度，舞台与侧栏使用同一可用高度；不再使用固定最小高度、侧栏最大高度或固定的窄屏高度。1200 像素以下，展开的侧栏与舞台上下等分剩余高度，各自内容按原规则滚动；收起侧栏时窄条排到舞台右侧，释放下面的空间。750 像素以下仍保留批次架在上方、折叠条横排的方式。

## 本机账本与导出

主存位置：`<DASHBOARD_HOME>/data/audition/<project>/<key>.json`。所有修改均为锁内重读、修改、原子写。

```json
{
  "schemaVersion": 1,
  "project": "rogue",
  "key": "dir-r1",
  "notes": [
    { "id": "唯一编号", "scene": "buy_fill", "group": "A", "text": "希望再轻一点", "at": "2026-09-12T08:00:00.000Z", "by": "负责人", "editedAt": "2026-09-12T08:05:00.000Z" }
  ],
  "marks": { "[\"A\",\"buy_fill\"]": "up" },
  "verdicts": { "A": "like" },
  "verdictReasons": { "A": { "text": "清楚又耐听", "at": "2026-09-12T08:06:00.000Z" } },
  "review": { "state": "已审阅", "at": "2026-09-12T08:00:00.000Z", "by": "负责人" }
}
```

`notes[].scene/group` 未指定时为 `null`。`marks` 用 `JSON.stringify([group, scene])` 作键，值是 `up` / `down`；取消时删除该键。`verdicts` 以组编号作键，值为 `like` / `meh` / `dislike`，取消时删除。未审阅的 `review` 为 `null`。

修改批注只更新原条目的 `text` 和 `editedAt`（ISO 时间），`id`、创建时间、作者与归属不变。`editedAt` 在未编辑的旧批注中可缺省。`verdictReasons` 保存组原因及保存时间；旧账本缺少时读回补 `{}`，不迁移、不改 `schemaVersion: 1` 的含义。请求不传 `reason` 保留原因，传空串或 `null` 删除，`value: null` 无条件一并删除该组原因。读取旧账本补默认不会写盘，导出自然包含补齐的新字段，索引汇总结构保持原样。

批注追加后镜像到 `batch.task` 的看板卡，格式为 `试听台批注〔批次标题·场景名或整批·组名或全部〕正文`。镜像通过既有命令的参数数组执行；失败仍保留主存，回包标明 `mirrored: false` 与 `mirrorError`。删除本机批注不会删掉已写入看板历史的镜像留言。

批注修改镜像为 `试听台批注(修改)〔批次标题·场景名或整批·组名或全部〕新内容`。保存有效的整组倾向或修改其原因时，镜像为 `试听台整组倾向〔批次标题·组名〕喜欢/一般/不喜欢——原因`，没有原因时末尾为 `——(未写原因)`。清除倾向仅清本机记录，不改已写入看板的历史留言。两类镜像均复用新增批注的参数数组与失败处理，镜像失败不回滚主存。

「导出批注到仓库」将账本写入 `<docsRoot>/docs/design/audio/试听台/批注/<key>.json`，返回相对路径。此操作不执行任何 Git 命令，也不改索引；由派单方收取导出文件。

## 接口摘要

模块未开时下列接口统一返回 404。写操作沿用主服务同源校验与请求体上限。

| 请求 | 结果或写入内容 |
|---|---|
| `GET /api/audition/index?project=` | `{ok, project, index, summaries}`；summaries 按批次编号返回 `{notes, up, down, review}` |
| `GET /api/audition/batch?project=&key=` | `{ok, batch, baseDir, problems}` |
| `GET /api/audition/file?project=&path=` | 原始二进制；白名单 `.mp3 .ogg .wav .html .htm .png .jpg .jpeg .webp .svg`，单文件最多 30MB |
| `GET /api/audition/state?project=&key=` | `{ok, state}`；没有主存时返回空账本 |
| `POST /api/audition/note` | `{project,key,scene?,group?,text}`，正文 1～4000 字；返回 `{ok,state,note,mirrored,mirrorError?}` |
| `POST /api/audition/note/update` | `{project,key,id,text}`，正文 trim 后 1～4000 字；锁内查找，缺失返回 404，非法正文返回 400；成功返回 `{ok,state,note,mirrored,mirrorError?}` |
| `POST /api/audition/note/delete` | `{project,key,id}` |
| `POST /api/audition/mark` | `{project,key,scene,group,value:'up'或'down'或null}` |
| `POST /api/audition/verdict` | `{project,key,group,value:'like'或'meh'或'dislike'或null,reason?:string或null}`；原因 trim 后 0～2000 字，非法值返回 400；有效倾向回包包含镜像结果 |
| `POST /api/audition/review` | `{project,key,state:'已审阅'或'未审阅'}` |
| `POST /api/audition/export` | `{project,key}`，返回 `{ok,path}` |

音频返回 `Accept-Ranges: bytes`，合法单区间为 206 并带 `Content-Range`；支持起止、开放结束及后缀范围，非法或多区间为 416。HTML 的类型为 `text/html; charset=utf-8`；其余文件使用对应音频/图片 MIME，绝不按文本解码声音文件。除导出外的写接口返回更新后的 `{ok,state}`。

测试位于 `test/auditionApi.test.cjs`，使用临时数据根、临时文档根和镜像桩；真实模块接线另由 `test/modules.test.cjs` 覆盖。本施工单的单测、类型检查、构建及界面扫描均由派单器统一运行。
